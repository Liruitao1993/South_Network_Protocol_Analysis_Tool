# 协议9 MAC 帧头 / MSDU / 物理块（PB）字段表 —— 组帧第一期依据

**来源**：同 `01-fc-field-tables.md`（第4部分 数据链路层通信协议，文本校对版）。

---

## 1. MAC 帧总格式（L247-260）

```
MAC帧 = MAC帧头(32B 或 12B) + MSDU + 完整性校验(4B, CRC-32)
无线 MAC帧 = 单跳MAC帧头(4B) + MSDU + 完整性校验(4B)     ← 版本2，仅无线
```

- 帧头选择：**用长MSDU发送原语 → 32B 长帧头；短MSDU发送原语 → 12B 短帧头**（L251）
- 完整性校验：**"计算完整性校验值时，不包括MAC帧头"**（L521）→ CRC-32 覆盖 = MSDU 载荷，与解析器 `_parse_mac_frame` L3436-3441 一致；**小端 4 字节**存放

## 2. MAC 长帧头（表 7，L315-341）

| 字段 | 字节 | 比特 | bit | 备注 |
| --- | --- | --- | --- | --- |
| 帧头类型 | 0 | 0 | 1 | 0=32字节长帧头 / 1=12字节短帧头（表4） |
| 版本 | 0 | 1-2 | 2 | 1=标准帧协议 / 2=单跳帧协议（表5） |

| ⤷ | 1 | 0-7 | | 高 8 位在字节1 |
| MSDU长度 | 2 | 0-7 | 16 | **小端**（解析器 L3285 `int.from_bytes(...,'little')`） |
| ⤷ | 3 | 0-7 | | |
| 原始目的TEI | 4 | 0-7 | 12 | |
| ⤷ | 5 | 0-3 | | |
| 原始源TEI | 5 | 4-7 | 12 | |
| ⤷ | 6 | 0-7 | | |
| 短网络标识低位 | 7 | 0-3 | 4 | |
| 重启次数 | 7 | 4-7 | 4 | 0-15 循环 |
| 路由跳数 | 8 | 0-3 | 4 | 单播=0 / 本地广播=1 / 全网广播按实际 |
| 广播方向 | 8 | 4-7 | 4 | 表9：1 下行 / 2 上行 |
| 发送类型 | 9 | 0-2 | 3 | 表10：0 单播需确认 / 1 全网广播不需 / 2 本地广播不需 / 3 全网广播需 / 4 本地广播需 |
| 发送次数限值 | 9 | 3-7 | 5 | 0 = 用本地默认重发次数 |
| MSDU序列号 | 10 | 0-7 | 16 | **小端**（解析器 L3370） |
| ⤷ | 11 | 0-7 | | |
| 目的MAC地址 | 12-17 | 0-7 | 48 | 6 字节，**按字节序低字节在前**（组帧时需与解析器展示的 `AA:BB:...` 顺序对齐） |
| 保留 | 18-21 | 0-7 | 32 | 解析器分两行展示（保留字段1: 18-21 / 保留字段2: 22-31） |
| 保留 | 22-31 | 0-7 | 80 | |

**TEI 字节排序规律（表 8，L346-357 + 实例 L357）**
> 例：原始目的TEI=0x123，原始源TEI=0x456 → 第4字节=0x23，第5字节=0x61，第6字节=0x45

→ 即「低字节在前，低位在前」，与解析器 `dest_tei = b4 | ((b5 & 0x0F) << 8)`、`src_tei = ((b5 >> 4) & 0x0F) | (b6 << 4)` 完全一致。**这条实例可直接作为组帧的单元 oracle**（0x123/0x456 → `23 61 45`）。

## 3. MAC 短帧头（表 11，L455-478）

与长帧头**字节 0-11 完全相同**，仅去掉「目的MAC地址(12-17) + 保留(18-21) + 保留(22-31)」→ 共 12 字节（L481）。

| 字段 | 字节 | 大小 |
| --- | --- | --- |
| 原始目的地址 | 0-5 | 48 |
| 原始源地址 | 6-11 | 48 |

### 5.2 MSDU 短帧头（表 2，L230-236）
| 字段 | 字节 | 大小 |
| --- | --- | --- |
| VLAN标签 | 0 | 8 |

> **组帧影响**：MSDU 短帧头 = `VLAN(1B) + MSDU类型(1B)`，**是应用层报文的既有前缀**。

## 6. 物理块（PB）格式

### 6.1 PB 结构与尺寸（L1483-1500）
```
PB = 物理块头(4B) + 物理块体 + 保留字节(1B) + 物理块检查序列(3B)
```
| PB 总长 | 块体长 |
| --- | --- |
| 520 | 512 |
| 264 | 256 |
| 136 | 128 |
| 72 | 64 |
| 40 | 32（HRF） |
| 16 | 8 |

> 校验：**保留字节计入 PBCS 校验范围**（L1586）→ PBCS = CRC-24(PBH + 块体 + 保留)，与解析器 L1579-1581 一致。
> 解析器另有「`pb_size` 与帧长不符时按 `offset+count×size==帧长` 推断」的容错（L1495），**组帧侧不必推断，直接算准**。

### 6.2 物理块头（表 47，L1513-1522）
| 字段 | 字节 | 比特 | bit |
| --- | --- | --- | --- |
| 序列号 | 0 | 0-7 | 16 |
| ⤷ | 1 | 0-7 | |
| 聚合标志 | 2 | 0 | 1（0 单 MAC 帧 / 1 含级联头） |
| 保留 | 2 | 1-7 | 15 |
| ⤷ | 3 | 0-7 | |

**序列号 16bit 小端**（解析器 L1521 `int.from_bytes(pb_data[0:2],'little')`）。
⚠ 解析器把 `保留` 读作 `((b2>>1)&0x7F) | (b3<<7)`（L1549）——即**继承 bit1-7 跨到字节3**，与文档「保留 2:1-7 + 3:0-7」一致。

### 6.3 级联头（表 48，L1543-1552）—— 聚合帧，第一期不做
| 字段 | 字节 | 比特 | bit |
| --- | --- | --- | --- |
| 级联数据块长度 | 0 | 0-7 | 12 |
| ⤷ | 1 | 0-3 | |
| 级联块起始标识 | 1 | 4 | 1 |
| 级联块结束标识 | 1 | 5 | 1 |
| 保留 | 1 | 6-7 | 2 |

### 6.4 16 字节 PB 特例（表 49，L1573-1586）—— 第一期不做
序列号(0-1) + 保留(2-3) + 报文ID(4 bit0-3) + 报文内容(4 bit4-7 + 5-11 = 60bit) + 保留(12) + PBCS(13-15)。

## 7. 组帧必须自动计算的三处校验（顺序与范围是硬契约）

| 校验 | 覆盖范围 | 算法 | 存放 |
| --- | --- | --- | --- |
| FCCS | FC 字节 0-12 | CRC-24 | FC 字节 13-15，**小端** |
| PBCS | PBH + 块体 + 保留字节 | CRC-24 | PB 尾 3 字节，**小端** |
| MAC 完整性校验 | **MSDU 载荷**（不含 MAC 头） | CRC-32 (IEEE) | MAC 帧尾 4 字节，**小端** |

解析器实现出处：`_crc24`(L730) / `_crc32_ieee`(L725)；调用处 L1992 / L1581 / L3438。

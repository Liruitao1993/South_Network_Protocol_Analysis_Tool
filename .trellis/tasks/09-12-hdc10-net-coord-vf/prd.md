# HDC 1.0 网间协调帧可变区域结构化解析

## Goal

协议11（HDC 1.0，Q/GDW 12087.42-2020）的 FC 可变区域里，**网间协调帧**（定界符类型 3）目前只输出一行占位「待实现」，用户看不到任何字段。本任务按文档 4-2 部分把网间协调帧可变区域结构化解析出来。

## Confirmed Facts（代码证据）

- 占位点两处：`hdc10_parser.py:437`（PLC 通道）、`hdc10_parser.py:446`（HRF 通道），内容均为 `("  可变区域(网间协调)", "", "", "待实现", base, offset + 12)`。
- 同文件已有可参照的兄弟实现：
  - 信标帧 `_parse_fc_vf_beacon`（含 HDC 1.0 信标条目 2 字节长度字段的正确口径——AGENTS.md §8 陷阱 25：条目内容 = `total_len - 3`）
  - SOF/SACK 帧的可变区域解析（`_parse_fc_vf_*` 系列）
- 参考文档：`国网新一代协议/HDC-国网双模协议/双模通信互联互通技术规范 第4-2部分：数据链路层通信协议.md`（网间协调帧定义 + 表号）；同类新一代文档 `国网新一代协议/双模通信互联互通技术规范 第4-2部分：数据链路层通信协议.md` 可作对照。
- 真实报文回归资产：`test/test_hdc10_real.py` + `test/hdc10_real_frames.pkl`（119 个真实 PB 帧，TMI 遍历测试日志提取）与 `国网新一代协议/HDC-国网双模协议/TMI模式遍历测试_频段1__All.log`（4500+ `Origin sof pb:'<hex>'` 行）。
- 现有测试：`test/test_hdc10.py`（20 项，含时隙分配条目 0xC0 长度字段、发现信标省略非中央信标信息）。

## Requirements

### R1 网间协调帧可变区域解析（PLC + HRF 两条路径一致）
- 按文档 4-2 部分网间协调帧的帧控制可变区域定义，逐字段输出（字段名/原始 hex/解析值/说明 + 起止偏移，7 元组行）。
- 若可变区域含**管理信息条目**（TLV 形式），复用既有条目解析约定（**长度字段 2 字节、内容 = total_len - 3**，见 AGENTS.md §8 陷阱 25 与 `test_hdc10.py::test_entry4_content_length`）。
- HRF（无线）通道的差异（若有）单独分支，不共用 PL C 的口径强推。

### R2 偏移与容错
- 行偏移必须落在 FC 可变区域真实范围内（`base`/`offset + 12` 的现有占位偏移即为已知长度：可变区域 12 字节 —— 需先核对是否所有网间协调帧都是 12 字节）。
- 变长/截断帧：尽力解析 + `⚠` 提示行，不抛异常（沿用本仓"字段声明与实际不一致时容错显示"原则，AGENTS.md §8 陷阱 23）。

### R3 真实报文验证
- 用 `test/hdc10_real_frames.pkl` 全量跑一遍，统计网间协调帧数量并断言解析不崩、字段行非空；至少 1 个真实网间协调帧（若 pkl 中存在）做字段级 golden 断言。
- 若 pkl 中没有定界符类型 3 的帧，则按文档构造最小合法帧（FC + 可变区域）并在测试中注明"构造帧"。

### R4 测试与文档
- 扩展 `test/test_hdc10.py`（或新增 `test/test_hdc10_netcoord.py`）：字段行断言 + 截断容错 + 真实帧回归。
- `AGENTS.md` §3/§8（若有新的条目口径结论）与 `CHANGELOG` 同步；`release_check.py` 保持全绿。

## Acceptance Criteria

1. PLC 与 HRF 两条路径下，网间协调帧不再输出「待实现」，而是逐字段行（字段名/原始值/解析值/说明 + 偏移）。
2. 含管理信息条目时按 2 字节长度字段口径解析（内容长度 = total_len - 3）。
3. 截断/异常帧给出 `⚠` 提示且不崩。
4. `test/test_hdc10.py` + `test/test_hdc10_real.py` 全过；新断言覆盖网间协调帧。
5. `python release_check.py` 无 FAIL/WARN。

## Out of Scope

- 不改协议10（`gw_new_gen_parser.py`）的对应逻辑——虽然两者共用文档体系，但协议10 内部按 FC 版本号自动区分 HDC 1.0/2.0，混改风险高；如协议10 侧也缺网间协调帧解析，另开子任务。
- 不做网间协调的**发送侧**（组帧）支持。
- 不重构 `hdc10_parser.py` 既有可变区域解析函数。

## Risks / Deferred

- 文档对网间协调帧可变区域的定义可能只有字段表没有实例：需先读 `第4-2部分` 相应表号，若字段存在歧义（如保留位数），以"标注保留 + 原始 hex"方式输出并在 PRD 评审时确认。
- 可变区域长度"12 字节"来自现有占位代码，未必对全部网间协调帧成立，需以文档 + 真实帧核对后再定偏移。

# 南网/国网新一代双通道（PLC/HRF）解析

## Goal

在南网新一代（协议9）和国网新一代（协议10）的单帧解析中，增加通道类型选项（PLC 载波 / HRF 无线）。选不同通道时，FC 可变区域字段、PB 大小映射表、MCS/TMI 显示等按对应通道规范解析。

## Background

现有解析器只实现了 PLC 载波通道的帧格式。实际上两个协议都是双模（载波+无线）规范：

- **FC 帧**：16 字节，固定字段一致，差异在可变区域
- **调制编码**：载波用 TMI（5bit，隐含 PB 大小+调制+copy，28 种），无线用 MCS（4bit，7种）+ 独立 PB 大小字段（4bit）
- **PB 大小**：载波 ISAC-PLC 5 种（16/72/136/264/520），无线 6 种（多 40 字节档）
- **帧长单位**：载波 10μs，无线 100μs
- **无线限制**：仅 1 个 PB，不分片

- SOF 可变区域：`_parse_mpdu_sof_bplc`（行992）、`_parse_mpdu_sof_isac`（行1050）
- PB size 表：`ISAC_PB_MAP`（行612），查询函数 `_get_pb_size(tmi, version)`（行620）
- GUI 解析级别：`main_gui.py:567-578`，6 种

**国网新一代（GW）**
- 解析器：`gw_new_gen_parser.py`，主类 `GWNewGenParser`

- 版本区分：HDC 1.0 / 2.0，从 FC 字节12高4位取（行242-248）
- PB size：没有 TMI→PB size 映射表（靠符号数+调制推导）
- GUI 解析级别：`main_gui.py:626-660`，7 种

## Requirements

### R1. GUI 通道切换选项

- 南网新一代（协议9）解析级别旁新增「通道」下拉框：PLC 载波 / HRF 无线
- 国网新一代（协议10）解析级别旁新增「通道」下拉框：PLC 载波 / HRF 无线
- 默认 PLC 载波
- 切换通道后，如果输入框有内容则自动重新触发解析
- 通道选择存 config.json 持久化

### R2. 南网新一代 FC 可变区域按通道解析

- **PLC 模式**：现有逻辑不变（BPLC / ISAC-PLC 按版本号自动区分）
- **HRF 模式**：
  - 信标帧：按无线信标可变区域解析（时间戳/周期计数/源TEI/MCS/PB大小/保留字段）
  - SOF 帧：按无线 SOF 可变区域解析（源TEI/目的TEI/链路标识/帧长/PB大小/MCS/TEI过滤/重传）
  - SACK 帧：按无线 SACK 可变区域解析
  - 帧长单位显示为 100μs
  - 物理块个数恒为 1（无线仅支持 1 个 PB）

### R3. 国网新一代 FC 可变区域按通道解析

- **PLC 模式**：现有逻辑不变
- **HRF 模式**：
  - 信标帧：按无线信标可变区域解析
  - SOF 帧：按无线 SOF 可变区域解析
  - SACK 帧：按无线 SACK 可变区域解析
  - 帧长单位 100μs

### R4. PB 大小按通道查表

- **南网 PLC**：沿用现有 `_get_pb_size(tmi, version)`
- **南网 HRF**：新增 `HRF_PB_SIZE` 表（6 种：16/40/72/136/264/520），从 FC 可变区域「载荷 PB 大小」字段直接索引
- **国网 HRF**：共用同一张 `HRF_PB_SIZE` 表
- PB 解析遍历时，HRF 模式只取第 1 个 PB

### R5. MCS 字段显示

- HRF 模式下 MCS 值（4bit）查表显示：调制方式 + 分集次数 + 码率
- MCS 表两边协议共用（0=4分集BPSK 1/2 ... 6=1分集16QAM 4/5）

## Out of Scope

- 物理层前导/STF/LTF/SIG/PHR 剥离（输入假设为数据链路层 FC 起始）
- 单跳 MAC 帧解析（仅无线有，MVP 不含）
- 批量解析通道切换（先只做单帧）
- 监控器通道切换（先只做单帧）
- 其他协议
- 国网 HDC 版（24bit NID）的无线模式

# 快捷解析小窗双卡片高度行为修正

## Goal

输入卡徽章行常驻使高度恒定；结果卡高度记住用户手动调整值，重复解析不再打回。

## 实测基线（修正前，offscreen 探针）

| 场景 | 观测 | 结论 |
|------|------|------|
| 空态（输入框为空） | `result_card` 隐藏，仅剩输入卡 84px | 符合要求 |
| 有解析结果 | `result_card` 浮出，窗口 392px | 符合要求 |
| 拖右下角缩放柄放大 +260px | 输入卡 114px → 114px 不变，多余高度全给结果卡 | 符合要求 |
| 清空输入 | 结果卡收回，窗口自动缩到 142px | 符合要求 |
| 手动放大到 692px 后改一个字节触发解析 | 窗口被打回 392px（`_fit_height` 用 sizeHint 重算） | **缺陷：手动尺寸丢失** |
| 空态 84px vs 展开态 114px | 输入卡高度随徽章行显隐跳变 30px | **不符合「输入卡高度不动」** |

## Requirements

### R1 输入卡高度恒定（徽章行常驻）

- 徽章行（协议下拉 / 帧长 / 校验徽章）空态也显示，不再随解析结果显隐。
- 输入卡高度在空态与展开态完全一致。
- 空态下允许预先手动选择协议（此前下拉框被隐藏，只能等解析出结果才能切）。
- 帧长徽章无报文时为空文本；校验徽章保持中性态，不显示 ✓/✗ 结论文本。

### R2 结果卡高度记住用户手动调整值

- 用户拖动右下角缩放柄后记录展开态高度 `user_height`。
- 此后每次解析（含 300ms 防抖触发的连续重解析）只更新表格内容，不再重置窗口高度。
- 空态（清空输入）仍收回为单输入卡形态，窗口按内容自适应到输入卡高度，但**不清除**
  `user_height`——再次输入时恢复用户设定高度。
- 从未手动调整过尺寸时保持既有内容自适应行为；上限仍为屏幕可用高度 80%。

### R3 不回归既有行为

- 输入卡垂直策略仍为 `Fixed`：任何窗口高度变化都不改变输入卡高度。
- 双卡投影/间距/缩放柄位置/主题 restyle 不变。
- 不新增数据文件，`南网协议解析工具.spec` 无需改动。
- 面板保持哑组件：不 import parser/validator。

## Acceptance Criteria

- [ ] 空态输入卡高度 == 展开态输入卡高度（offscreen 实测）
- [ ] `resize(+N)` 后输入卡高度不变、结果卡高度增加 N
- [ ] 手动放大窗口 → 触发 `_do_parse()` → 窗口高度保持手动值（不回缩）
- [ ] 手动放大 → 清空输入 → 收回到仅输入卡 → 再次输入 → 高度恢复手动值
- [ ] 未手动调整过尺寸时，解析/清空仍自动适配内容高度
- [ ] `test/test_quick_parse_panel.py` 全过；空态徽章行断言由「隐藏」改为「常驻」，
      并补 R1/R2 几何断言
- [ ] `main_gui.py:CHANGELOG` 与 `AGENTS.md` §10 同步本次行为变更

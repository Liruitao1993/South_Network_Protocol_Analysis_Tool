# PRD: 协议8（698.45）安徽分布式电源接入单元补充规约解析增强

## 背景

用户新增协议文档 `协议文档/8.698.45协议/安徽省2025年一批分布式电源接入单元补充技术协议.md`，在标准 698.45 基础上扩展了一批对象（OI）定义，覆盖分布式电源接入单元的光伏逆变器、专用断路器、调控调度等场景。现有解析器 `dl_t698_45_oi_lookup.py`（OI 名称/类绑定）、`dl_t698_45_data_decode.py`（数据业务解码）已支持标准对象，但**安徽补充规约的 17 个新增 OI 完全缺失**——查询时显示"未知对象"，GET/SET/ACTION 响应无法给出业务解码。

## 目标

让协议 8 解析器完整识别并解码安徽补充规约中的对象：

1. **OI 名称与类绑定补全**：17 个缺失 OI 的名称、接口类（IC）映射，查询页/表格显示正确名称而非「未知对象」。
2. **数据业务解码**：对新增 OI 的属性（电量、时间、状态、事件记录、档案结构等）按文档定义给出业务值（单位换算、enum 名称、structure 各成员、array 展开）。
3. **方法参数解码**：支持文档定义的方法（跳闸/合闸、开关机、负荷控制、调控计划增删清等）的参数结构解析。
4. **回归**：不破坏现有 698.45 对象解析与既有测试。

## 范围

### 纳入

- `dl_t698_45_oi_lookup.py`：OI_NAME_MAP / OI_TO_CLASS_ID 新增 17 个 OI；CLASS_ID_MAP 补充类 6/7/8/19 相关属性的名称（已有方法属性补充）。
- `dl_t698_45_data_decode.py`：`OI_UNIT_HINT` 补充新 OI 单位换算；`CLASS_ATTR_TEMPLATES` 新增类 6/7/8 的属性模板（long64 电量、发电时间、事件记录表、档案 structure、调控计划 array 等）；新增结构解码辅助（structure 成员、enum 命名、bit-string 状态字、date/date_time_s 可读化）。
- `dl_t698_45_apdu_parser.py`：方法参数解码（跳闸/合闸/开关机/负荷控制/调控计划）接入 ACTION-Request 等方法参数分支。
- `test/`：新增测试用例（合成 A-XDR 帧 + 断言业务值）。

### 排除

- 不改链路层帧结构（68 L L C ... 16）解析——文档未涉及。
- 不改 645/DLMS 等其他协议。
- 不新增协议下拉项——仍属协议 8（698.45）。

## 验收标准

1. `OILookup().OI_NAME_MAP` 覆盖全部 17 个新增 OI，`OI_TO_CLASS_ID` 绑定正确 IC。
2. 查询页输入这些 OI 显示正确中文名称。
3. 合成的 GET-Response / SET-Request / ACTION-Request 中带这些 OI 的帧，解析表格出现「数据业务」行且数值正确（如 发电量 2801 属性2 → `总发电量: XXX.XXXX kWh`）。
4. 方法参数（跳闸/合闸/开关机/负荷控制/调控计划）解析出结构成员。
5. `test/test_dl_t698_45_data_decode.py` 新增用例全过；`test/test_dl_t698_45.py`、`test/test_dl_t698_45_fujian.py`、`test/test_oad_enrichment.py` 回归全过。

# Reflex Web 版本发布管理（管理员上传 exe 自动发布）

## Goal

在 Reflex Web 版中新增管理员后台：登录后可上传 GUI 版 exe、填写版本号与更新说明，系统自动计算 SHA-256 并生成 `version.json`，完成发布。免去手动登录服务器上传文件、手动生成 version.json 的繁琐流程。

## Requirements

### 用户角色
- **游客**：看到现有所有功能页，看不到发布管理入口。
- **管理员**：登录后额外看到"发布管理"标签页，可上传 exe 并发布新版本。

### 认证
- 单管理员账号，密码哈希存储在服务端配置文件中（首次启动可设默认密码，支持修改）。
- 登录状态通过 Reflex State + 服务端 token/session 管理，刷新后需重新登录（或用 cookie 持久化，简化起见用 State 即可）。
- 密码错误次数过多无强制锁定（内网使用场景，简化处理）。
- 密码配置文件：`reflex_web/admin_config.json`，含 `password_hash`（sha256）字段，默认密码 `admin123`，首次登录提示修改。

### 发布管理页面
管理员登录后可见的功能：
1. **当前版本信息**：展示当前 `version.json` 的内容（版本号、文件名、大小、SHA-256、更新说明、发布时间）。
2. **上传发布表单**：
   - exe 文件上传（Reflex upload 组件，限 `.exe` 后缀，最大 500MB）。
   - 版本号输入（必填，如 `1.14.0`）。
   - 更新说明文本域（可选）。
   - 下载地址（自动填 `/download/文件名`，可手动修改为完整 URL）。
3. **发布操作**：
   - 点击"发布"后：保存 exe 到 `downloads/` 目录 → 计算 SHA-256 → 生成 `version.json` → 刷新当前版本显示。
   - 发布过程显示进度（上传进度由浏览器/Reflex 处理，SHA-256 计算显示百分比）。
   - 发布成功后旧 exe 自动备份到 `downloads/archive/` 目录（按版本号命名），可回滚。
4. **历史版本列表**：列出 `archive/` 目录中的历史版本，支持一键回滚（将指定版本恢复为当前版本，重写 version.json）。
5. **密码修改**：管理员可修改登录密码。

### 下载地址生成规则
- 默认生成完整 URL：`http://<当前访问host>/download/<文件名>`，客户端 `auto_updater.py` 可直接使用。
- 管理员可手动覆盖为其他地址。

### 安全约束
- 所有发布管理相关 API 和页面必须登录后才能访问，未登录访问返回 401 或跳转到登录。
- 上传文件严格校验后缀为 `.exe`，且 MIME 类型为 `application/octet-stream`。
- 文件名防目录穿越：只保留文件名部分，去除路径。
- 上传的 exe 在保存前做基本校验（PE 文件头 `MZ`），防止非 exe 伪装上传。

### 兼容性
- 不影响现有所有功能页（单帧解析、批量解析、组帧、对比、查询、工具、客户端下载）。
- 生成的 `version.json` 格式与现有 `auto_updater.py` 私有源格式完全兼容。
- 部署在 `10.1.10.172:8091` 的内嵌 exe 部署模式下可用。

## Acceptance Criteria

- [ ] 管理员可通过登录表单进入发布管理页面，错误密码被拒绝。
- [ ] 上传 exe + 填写版本号后，点击"发布"能成功：
  - [ ] exe 保存到 `reflex_web/downloads/` 目录
  - [ ] `version.json` 自动生成，含正确的 version、url、notes、sha256 字段
  - [ ] 旧版本 exe 备份到 `downloads/archive/`
- [ ] 生成的 `version.json` 中 `url` 字段为完整 URL（含 scheme+host），客户端可直接下载。
- [ ] 历史版本列表展示所有归档版本，可一键回滚到任意历史版本。
- [ ] 未登录用户看不到"发布管理"标签页，也无法通过直接访问执行发布操作。
- [ ] 密码可修改，修改后需重新登录。
- [ ] 现有所有功能页（单帧/批量/组帧/对比/查询/工具/下载）不受影响。
- [ ] 在内嵌部署模式（PyInstaller 打包的 Reflex exe）下正常工作。

## Notes

- 内网使用场景，安全要求适中；不过度设计。
- 与 `auto_updater.py` 的私有源格式保持完全一致：`{version, url, notes, sha256}`。
- 下载路由已存在（`/download/` 前缀，`run_app.py` 中的 `_serve_download` 中间件），直接复用。

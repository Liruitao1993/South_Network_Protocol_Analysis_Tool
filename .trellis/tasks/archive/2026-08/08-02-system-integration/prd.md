# 系统集成增强

## Goal

提升软件易用性和推广范围，让研发/测试人员日常工作中方便调用解析能力。
包含：开机自启、系统托盘、文件右键菜单、全局热键解析、命令行参数支持。

## Requirements

### R1. 开机自启
- 设置对话框中增加"开机自动启动"复选框
- 勾选后写入 Windows 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- 取消勾选后删除注册表项
- 启动时正常显示主窗口（不是系统托盘）
- 无需管理员权限（HKCU 级别）

### R2. 系统托盘
- 主窗口关闭按钮 → 最小化到系统托盘（不退出程序）
- 托盘图标左键单击 → 显示/隐藏主窗口
- 托盘右键菜单：显示主窗口 / 退出
- 关闭到托盘时提示"已最小化到系统托盘"（可选气泡通知）
- 托盘菜单中提供"开机自启"开关

### R3. 文件右键菜单
- 支持文件类型：.log, .txt, .hex, .bin
- 右键菜单层级："用协议解析工具解析" → 子菜单列出各协议类型
- 子菜单项：南网协议、国网协议、新一代载波、国网新一代、HDLC/DLMS、DLT645 等
- 点击后启动软件（已在运行则激活窗口），加载文件中内容并按所选协议解析
- 通过注册表 `HKCU\Software\Classes\*` 或具体扩展名实现
- 设置中提供"注册右键菜单"/"取消注册"按钮

### R4. 全局热键解析
- 默认热键：`Ctrl+Alt+X`（可在设置中修改；原定的 Ctrl+Alt+P 常被输入法/其它软件占用，改用已验证可用的组合）
- 按下热键后：读取剪贴板内容 → 提取 hex 字符串 → 自动识别/按当前协议解析 → 弹出解析结果窗口
- 解析结果窗口：简洁对话框，显示解析表格，支持复制
- 热键在设置中可修改、可启用/禁用
- 软件在后台运行（托盘状态）时热键也有效

### R5. 命令行参数
支持以下命令行参数：
- `--parse <hex_string>` — 直接解析指定 hex 字符串，启动后显示解析结果
- `--protocol <name>` — 指定协议类型（如 "南网新一代"、"国网新一代"、"HDLC" 等）
- `--file <path>` — 从文件读取内容解析
- `--minimized` — 启动后最小化到托盘
- 无参数 — 正常启动主窗口

### R6. 设置界面
- 在"设置"对话框中统一管理：开机自启、全局热键、文件右键菜单注册、关闭行为（退出/最小化到托盘）

## Acceptance Criteria

- [ ] 设置中勾选"开机自启"后，注册表 Run 键有对应项，重启后自动启动
- [ ] 点击关闭按钮，窗口缩到系统托盘，程序不退出
- [ ] 托盘左键显示/隐藏主窗口，右键菜单可退出
- [ ] .txt/.log/.hex 文件右键有"用协议解析工具解析"子菜单，列出所有协议
- [ ] 点击右键菜单项后，软件启动并直接显示该文件的解析结果
- [ ] 全局热键 Ctrl+Alt+X 可用，复制 hex 后按热键弹出解析结果
- [ ] 命令行 --parse 参数可直接解析并显示结果
- [ ] 命令行 --protocol 参数可指定协议
- [ ] 设置中可修改热键、注册/取消右键菜单、开关开机自启

## Out of Scope

- 浏览器扩展
- 安装包（installer）自动注册所有功能
- macOS/Linux 支持
- 多实例管理（允许多开）

## Technical Notes

- 注册表操作使用 winreg 模块（Python 标准库）
- 全局热键使用 QShortcut 不行（需要全局钩子），用 `keyboard` 库或 Windows API `RegisterHotKey`
- 系统托盘使用 QSystemTrayIcon
- 单实例：使用 QLocalServer/QLocalSocket 确保只有一个实例运行，命令行触发时激活已有实例并传参
- 已注册的右键菜单在卸载/删除时需清理

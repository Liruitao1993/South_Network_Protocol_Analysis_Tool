# 批量解析 Python 脚本预处理

## Goal

在批量解析标签页中，支持加载并执行用户自定义 Python 脚本，对输入的原始报文文本进行预处理（清洗、提取、转换），脚本可调用项目内置解析器，结果回填到批量输入框。

## Background

现有批量解析已有两套预处理机制：
- CLI 命令链（`pp_cli.py`）：管道式 find / excluding / replace / hex_extract 等内置命令
- LLM 智能预处理：通过 API 调用大模型清洗

两套机制均覆盖"常见文本清洗"场景，但遇到复杂或特化的清洗逻辑时表达力不足。用户需要用 Python 编写自定义预处理脚本，直接操作文本、调用项目内 parser，灵活度最高。

UI 相关锚点：
- 批量解析工具栏：`main_gui.py:1252` 起
- CLI 预处理组合框及执行按钮：`main_gui.py:1284`-`1334`
- 配置持久化路径：`self._config_path = Path(__file__).parent / "config.json"`（`main_gui.py:499`）
- CLI 命令持久化到 `pp_commands` 段：`main_gui.py:5521`

## Requirements

### R1. 脚本加载与管理

- 批量解析工具栏新增「脚本」相关控件：下拉选择框 + 加载按钮 + 运行按钮 + 管理按钮
- 支持通过文件对话框选择 `.py` 文件加载
- 已加载脚本记录保存到 `config.json` 的 `py_scripts` 段（列表，每项含 name 与 path）
- 下拉框可快速切换已保存脚本
- 支持删除下拉列表中脚本（仅移除记录，不删除磁盘文件）

### R2. 脚本执行

- 点击运行按钮后，读取 `batch_input` 当前文本作为输入，调用脚本处理，结果回填到 `batch_input`
- 执行在主线程同步运行（与 CLI 预处理一致的体验），超时或异常弹出错误提示
- 脚本通过约定的入口函数接收输入、返回输出

### R3. 脚本 API 契约

脚本必须定义以下入口函数之一，按优先级匹配：

```python
def process(text: str, context: dict) -> str:
    """主入口。text 为批量输入框原文，context 含辅助信息。返回处理后文本。"""
```

`context` 字典提供：
- `protocol_index`: 当前协议索引（int）
- `protocol_name`: 当前协议名称（str）
- `config_dir`: 配置文件所在目录（str）
- `parser`: 当前协议解析器实例（可调用 parse 等方法，按协议类型不同）

脚本可自由 `import` 项目内模块，使用项目内所有 parser、工具函数。

### R4. 执行反馈

- 成功：状态栏显示执行结果（行数变化、脚本名）
- 失败：弹出 QMessageBox 显示异常堆栈
- 空结果：提示"脚本输出为空"，不回填

### R5. 示例脚本

- 内置 2-3 个示例脚本，放到 `scripts/` 目录，首次启动自动注册到下拉列表
  - 示例1：通用 hex 提取（仅保留十六进制字符，每行一帧）
  - 示例2：TCP payload 提取（从 tcpdump 风格日志提取数据段）
  - 示例3：调用解析器做过滤（如只保留解析成功的帧）

### R6. 安全与兼容

- 脚本直接 exec 运行（信任本地文件），不加沙箱
- 脚本修改输入内容失败时，原输入内容不丢失
- 兼容现有 CLI 预处理、LLM 预处理，三者独立可串联使用

## Acceptance Criteria

- [ ] 批量解析工具栏可见脚本下拉框、加载、运行、管理按钮
- [ ] 通过文件对话框加载 .py 文件后，出现在下拉列表中，关闭重开后仍在
- [ ] 选择脚本后点击运行，batch_input 内容被脚本输出替换
- [ ] 脚本 `process(text, context)` 中可通过 `context['parser']` 调用解析器
- [ ] 脚本报错时弹出含 traceback 的错误框，原输入内容保留
- [ ] 示例脚本随项目发布，首次启动自动注册
- [ ] 删除脚本仅移除下拉列表记录，不删磁盘文件
- [ ] 不破坏现有 CLI 预处理与 LLM 预处理功能

## Out of Scope

- 逐帧处理脚本（帧级预处理，非文本级）
- 解析后处理 / 结果过滤脚本
- 脚本编辑器内嵌（用外部编辑器即可）
- 脚本沙箱 / 权限限制
- Web 版 / TUI 版同步（仅 GUI）

## Open Questions

无。所有关键决策已确认：预处理阶段运行、输入文本输出文本、可调用解析器、直接 exec 运行。

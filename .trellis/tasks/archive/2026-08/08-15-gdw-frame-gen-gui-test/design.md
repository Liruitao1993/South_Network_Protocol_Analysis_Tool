# Design：国网协议 7 组帧 GUI 测试与修复

## 方法

1. **代码定位**
   - 找到 `main_gui.py` 中协议 7 组帧的入口和 UI 代码。
   - 定位 `protocol_tool.py` 或相关组帧工具函数。
   - 找到 `gdw10376_parser.py` 中组帧相关函数。

2. **功能映射**
   - 列出协议 7 组帧涉及的所有 GUI 字段和按钮。
   - 建立字段 → 后端函数 → 生成帧的映射。

3. **系统化测试**
   - 启动 GUI，切换到协议 7，进入组帧标签页。
   - 按字段逐个测试：
     - 默认值
     - 边界值
     - 异常值
     - 空值
   - 测试所有预设命令按钮。
   - 测试生成后的复制、跳转解析。

4. **问题修复**
   - 记录每个问题：现象、复现步骤、根因、修复方案。
   - 优先修复崩溃、卡死、生成结果错误。
   - 再处理输入校验、提示信息、UI 对齐。

5. **回归验证**
   - 修复后重新测试协议 7 组帧全流程。
   - 快速回归其他协议组帧，确保无影响。

# GUI 按钮添加图标

## Goal

为软件的 GUI 按钮添加图标，提升用户体验：主要操作按钮配图，让用户一眼识别功能，减少纯文字按钮的阅读负担。

## Background

- 上一任务「统一全应用按钮风格」（08-26-unify-button-style）已完成：全应用按钮形状/颜色/状态统一（`btnKind` 语义类 + `set_btn()`），但**未添加图标**。
- 当前部分图标按钮（批量工具栏 ★保存 / ×删除 / ?帮助）用文本字形模拟，风格不统一。
- `icons/` 目录已存在并打包（spec 里 `('icons', 'icons')`），目前主要用于 app 图标等资源。
- 方案已确认：**Qt 内置标准图标**（`QStyle.StandardPixmap` + `QIcon.fromTheme`），零额外资源、无打包改动、跨平台稳定。

## Requirements

- 为主要的、语义明确的功能按钮添加 Qt 内置标准图标（如解析、校验、保存、删除、导出、打开串口、停止、刷新、清空、查询、发送、生成、对比、复制等）。
- 图标按钮保留原文字 label（图标 + 文字并存），不改变现有文字、布局与 `btnKind` 语义色。
- 图标尺寸适中（16px 左右），随主题/高 DPI 正常显示，不与文字挤占。
- 对无合适 Qt 标准图标的特殊按钮（★ × ?）保留现有文本字形或就近映射，不强行硬配。
- 不改变按钮布局/尺寸语义、不改变 `set_btn` 风格体系、不引入新资源文件、不改 spec 打包。

## Acceptance Criteria

- [ ] 主要页面（单帧解析、批量解析、组帧、对比、TCP 监控、监控器、测试方案、档案、拓扑、报文工具）的主要操作按钮均带图标。
- [ ] 图标 + 文字并存，文字仍完整显示、按钮语义色（btnKind）不变。
- [ ] 浅色/暗色/毛玻璃三主题下图标均清晰可见、颜色与主题适配。
- [ ] 高 DPI 缩放下图标不模糊、不溢出。
- [ ] 无合适的 Qt 标准图标的按钮保持原样或就近映射，不出现怪异/不匹配图标。
- [ ] 语法检查通过，offscreen 三主题启动主窗口无异常。

## Out of Scope

- 不自建自定义图标集（SVG/PNG 资源）——已否决。
- 不改 spec 打包、不新增资源文件。
- 不改按钮形状/颜色/尺寸语义（那是上一任务范围）。

# TCP 流量监控器

## Goal

在协议解析工具中新增 TCP 流量监控标签页，类似简化版 Wireshark，专门用于捕获和分析国网新一代 / 南网新一代协议的 TCP 流量。用户可以选择网卡、设置过滤条件、查看 TCP 流列表，选中某条流后自动按应用层协议帧解析展示。

## Requirements

### R1. 标签页集成

- 在主窗口 `tab_widget` 新增 "TCP监控" 标签页，始终可见（独立于协议切换）
- 标签页内容由 `TCPMonitorWidget` 类实现，放在 `monitor/tcp_monitor.py`

### R2. 网卡选择与抓包控制

- 顶部工具栏：网卡选择下拉框 + 刷新按钮
- 开始 / 停止抓包按钮
- scapy `sniff` 实现，后台线程运行，不阻塞 UI
- Windows 需 npcap，启动失败时友好提示安装 npcap

### R3. TCP 流列表

- 上半部分：TCP 流列表表格
- 列：流ID、源IP:端口、目的IP:端口、包数、字节数、最新时间
- 点击流 → 切换关注该流，下方显示该流的应用层报文
- 流列表支持右键：复制、关注此流

### R4. 过滤设置

- 过滤输入框（类 Wireshark 过滤条）
- 支持 BPF 语法：`host 192.168.1.1`, `port 8080`, `tcp port 5000`, `src host 10.0.0.1`
- 抓包前设置过滤，抓包时由 scapy BPF 过滤器执行
- 抓包过程中修改过滤：重新开始抓包时生效

### R5. 报文列表 + 详情面板

- 下半部分左侧：当前关注流的应用层帧列表
  - 列：时间、方向、长度、协议类型、摘要
- 下半部分右侧：选中帧的解析结果表格
  - 4 列：字段、原始值、解析值、说明
  - 自动调用对应协议解析器（国网新一代 / 南网新一代）

### R6. TCP 流重组 + 帧切分

- 每条 TCP 流维护双向字节缓冲区
- 检测 SOF 帧头（0xC0）+ 长度字段切分完整应用帧
- 完整帧才送解析器和显示
- 处理跨 TCP segment 的帧分片

### R7. 自动协议识别

- 根据帧头特征自动判断协议（国网新一代 / 南网新一代）
- 也可在工具栏手动切换协议解析

### R8. 基础操作

- 清空按钮：清除所有捕获数据
- 表格复制：所有结果表格支持右键复制 + Ctrl+C（复用 `_setup_table_copy_menu` 模式）

## Acceptance Criteria

- [ ] "TCP监控" 标签页正常显示，不影响其他标签页
- [ ] 网卡列表正确显示系统网卡
- [ ] 点击开始抓包后能捕获 TCP 包，流列表实时更新
- [ ] BPF 过滤表达式生效（host / port）
- [ ] TCP 流重组正确，跨 segment 的帧能完整切分
- [ ] 选中流后，下方报文列表显示应用层帧
- [ ] 选中帧后，右侧解析结果自动显示
- [ ] 国网新一代和南网新一代协议都能解析
- [ ] 停止抓包后界面稳定，无崩溃
- [ ] 未安装 npcap / scapy 时给出友好提示，不崩溃

## Out of Scope

- UDP 流量
- pcap 文件保存 / 加载
- 非国网/南网新一代协议的深度解析
- 吞吐量图表等图形统计
- 过滤语法提示 / 自动补全

## Technical Notes

- 抓包库：scapy（需系统安装 npcap / libpcap）
- 解析器复用：`GWNewGenParser.parse_to_table()` / `CSGNewGenParser.parse_to_table()`
- 帧切分依据：SOF = 0xC0，帧长从帧头读取（参考现有解析器帧头解析）
- 线程模型：抓包线程 → 信号 → 主线程更新 UI
- 架构参考：`monitor/frame_monitor.py`（上下分栏 + 左侧列表 + 右侧详情）

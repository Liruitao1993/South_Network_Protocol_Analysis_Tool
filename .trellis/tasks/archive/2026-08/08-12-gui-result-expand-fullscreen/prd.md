# PRD：校验结果展开/收缩 + 解析结果表格全屏/恢复

## 背景

单帧解析页「校验结果」区（`verify_group`）内容随校验项增多而拉高，挤压解析结果表格空间；解析结果表格本身无法放大查看。用户要求：
1. 「校验结果」输出提供 **展开 / 收缩** 按钮
2. **所有解析结果表格**提供 **全屏 / 恢复** 按钮

## 需求

1. **校验结果展开/收缩**（单帧解析页 `result_layout` 内 `verify_group`）：
   - 组内标题下方新增右对齐按钮行：`展开` / `收缩`（默认展开态：展开禁用、收缩可用）
   - 内容 `verify_label` 移入 `QScrollArea`（保持换行/Consolas/配色行为）
   - 收缩：隐藏内容滚动区，组高收缩至仅标题+按钮行（`展开` 重新可用）
   - 展开：恢复内容显示，取消高度限制
   - `_display_verify_result` 的组边框配色（绿/红）不受影响
2. **解析结果表格全屏/恢复**：
   - 通用辅助 `_make_fullscreen_controls(hide_widgets)` → 右对齐「全屏 / 恢复」按钮对（全屏隐藏兄弟控件让表格撑满，恢复还原）
   - 应用位置：
     - 单帧解析：`result_layout` 的导出按钮行加 全屏/恢复（隐藏 `input_group` + `verify_group`）
     - 批量摘要表：`summary_group` 内加 全屏/恢复（隐藏 `result_splitter.widget(1)` 详情组）
     - 批量详情表：`detail_group` 内加 全屏/恢复（隐藏 `result_splitter.widget(0)` 摘要组 + `batch_detail_hex` 行）

## 约束

- 仅改 `main_gui.py`（布局 + 方法），不涉及 parser/validator
- 主题/字体设置路径不变（按钮沿用 `_ui_font(-1)`）
- 各按钮对状态互斥（全屏时全屏禁用、恢复可用，反之亦然）
- 现有样式：`_display_verify_result` 边框配色、`_restyle_for_theme` 动态控件适配须保持

## 验收标准

1. 校验结果区出现「展开/收缩」按钮；点收缩后内容消失、组高缩小、展开按钮可用；点展开恢复内容。
2. 单帧解析结果表「全屏」后输入区+校验结果区隐藏、表格撑满；「恢复」还原。
3. 批量摘要/详情表各有「全屏/恢复」；全屏隐藏对侧面板，恢复还原。
4. 现有功能回归：解析/校验/批量解析行为不变（offscreen 冒烟 + 既有测试套件）。

# PRD：LME 未知/厂商扩展条目智能解码

## 背景

DI=FF00DD01 双模STA应答中，分类 6/7 为厂商扩展条目（手册 4.3 仅定义分类 0~5）。现场帧示例：
- 条目1 分类7/数据1（31B，BIN）：前 12B 二进制 + 内嵌 ASCII 型号 `LSX830A-GPR001C-D2`，当前只显示整段 hex
- 条目2 分类7/数据2（3B，BIN `000003`）：当前 hex 原样显示

## 需求

1. 未知条目（不在 `LME_INFO_ENTRIES` 字典）BIN 数据中提取连续可打印 ASCII 子串（≥4 字符），解析值显示为 `二进制前缀hex + ASCII"<串>"`（型号/版本等可读信息不被埋没）。
2. 无 ASCII 的短 BIN 数据（≤8B）：附加小端/大端数值解读。
3. 分类 ID ≥ 6：说明列标注"厂商扩展分类，手册未定义语义"。
4. 已知条目解码行为不变；4 元组列位契约不变。

## 验收

1. 现场帧分类7/数据1 解析值含 `LSX830A-GPR001C-D2`。
2. 分类7/数据2 解析值含数值解读（小端 196608 / 大端 3）。
3. 说明列对分类7标注"厂商扩展"。
4. `test/test_dlt645_lme.py` 既有 43 项不回归，新增断言通过。

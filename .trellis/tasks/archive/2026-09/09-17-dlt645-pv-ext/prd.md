# 协议6 光伏协议转换单元 645 扩展协议解析

## Goal

让协议6（DL/T 645-2007）能正确解析《低压分布式光伏协议转换单元技术规范书》定义的 **DL/T 645-2007 扩展协议**：三组扩展数据标识（变量/参数/事件）与扩展控制码 `0FH`/`8FH`，从当前「未知数据标识 + 未知功能码0FH」变为逐字段可读，桌面与 Reflex Web 两端一致。

## Background

- 用户新增文档 `协议文档/6.645协议/附件1：协议转换单元【低压分布式光伏协议转换单元】-技术规范书0625.docx`，已用项目脚本 `convert_docx_to_md.py` 转换为同名同目录 `.md`（517 段落 / 36 表格 / 77,407 B）。
- 文档规定：协议转换单元**上行、下行、本地维护均遵循 DL/T 645—2007 协议及其扩展协议**；扩展定义集中在文档 `# 协议转换单元DL/T 645-2007扩展协议`（第 1024 行起，含三张数据标识表）与附录 I.3.3.1（控制码 `0FH`/`8FH` 透传帧）。
- 现状（已实测）：
  - `dlt645_di.json` 有 1099 条 DI，**不含** `02E6`/`03E6`/`04E6` 三组 → `di_desc` 显示「未知数据标识」。
  - `dlt645_data_codec.FUNC_NAMES` 无 `0x0F` → 显示「未知功能码0FH」。
  - 解析器已有「按 DI + 控制码分派深度解析」的成熟模式（LME 接口：`_LME_DI_CODES` + `lme_info_entry_parser.parse_lme_dlt645`），本次复用该模式。

## Requirements

- R1 三组扩展 DI 全部可识别（名称/单位/数据格式/长度），并在解析结果表格中展开为逐字段行。
- R2 数据块按**「数据长度」列**切分（文档「数据格式」列仅作显示提示，不能机械解析），每值按 645 规则解码（数据域已减 `0x33`，多字节 BCD 低字节在前）。
- R3 语义规则必须落实：① 有功/无功功率**最高位为符号位**（0=发电/正、1=用电/负，范围 ±7999.9999）；② 单相设备 B/C 相显示 `FF`，须标注而非当成数值；③ 事件块中「从左往右每个字节分别表示逆变器 12、11、…、1」；④ 调控结果枚举（`00` 成功 / `01` 未调 / `02` 失败 / `03` 不支持 / `04` 其他，`FF` 不存在）；⑤ `DI0` 语义按组区分（变量/参数组 = 逆变器序号 `01`~`0C`，`FF` = 下挂全部；事件记录组 = 第 N 次记录，`0x32`=50）。
- R4 扩展控制码 `0FH`（主站请求）/ `8FH`（从站应答，DIR=1 + FUNC=0x0F）可识别，数据域按「数据标识 + 透传数据」呈现（`L = 04H + 数据长度`）。
- R5 名称与数据格式**单一来源**：新 DI 表只定义一处，解析器、查询页、Web 三处共用；`dlt645_di.json`（生成物，AGENTS.md §4.5 禁止手改）不得手工修改。
- R6 桌面与 Web 同源：查询页数据源与解析呈现两端一致，并有对拍断言防漂移（陷阱 31）。
- R7 未知/未覆盖 DI 与未知控制码保持既有兜底行为，不回归。
- R8 新模块为**纯逻辑无 Qt**（可脚本测试），不引入跨帧可变实例状态（陷阱 41）。

## Scope

### In Scope
- 新增扩展模块（DI 表 + 深度解码，含三组 DI 与全部数据块）。
- `dlt645_parser.py`：DI 表合并 + 扩展 DI 深度解析分派 + `0FH`/`8FH` 透传帧呈现。
- `dlt645_data_codec.py`：`0x0F` 功能码名称（`0x8F` 复用同一 FUNC 条目）。
- 查询页数据源（`dlt645_di_lookup.py`）与 Web 侧（`web_utils.py` / `lookup_utils.py`）同步。
- 新增测试套件并登记 `release_check.py:CORE_TESTS`。

### Out of Scope（另行立项）
- **组帧**：`dlt645_frame_gen.py` / `dlt645_frame_schema.py` 的写入/调节命令下发（本任务只做解析）。
- **645 虚拟表**（`dlt645_meter_sim_widget.py` / `dlt645_sim/`）对这些 DI 的从站应答与 LME 下发。
- 附录 G 的各厂商光伏逆变器协议（Modbus 等，属逆变器侧）。
- 附录 I.3.3.2 的 DL/T 698.45（OI `F209`、IC 22 方法 127）透传（属协议8）。
- 文档中硬件/环境/结构/检验类章节。

## Acceptance Criteria

- [ ] A1 变量类：`02E60101`（逆变器1电压块）解出 A/B/C 三相电压值（`V`），字段名/原始值/解析值/说明四列齐全。
- [ ] A2 单相设备：B/C 相为 `FF` 时显示「FF(单相无该相)」类标注，不被当成数值。
- [ ] A3 功率符号位：`02E60301` 最高位=1 时解析为**负值**（用电），=0 时为正（发电），含边界 `±7999.9999`。
- [ ] A4 `DI0=FF`（`02E601FF`）：显示为「下挂所有光伏逆变器」。
- [ ] A5 参数类：`04E60401`（运行状态：0 开机/1 关机）、`04E60301`（输出类型：00 单相/01 三相）按枚举呈现；`04E60001`（数量 + 通信地址表）按文档字节切分呈现。
- [ ] A6 事件类：`03E60101`（开关机控制事件块）解出 发生时刻/结束时刻/事件类型/调控结果，且**调控结果按逆变器 12→1 的字节序**呈现。
- [ ] A7 事件序号：`03E60132` 呈现为「第 50 次」记录（`0x32`=50），`03E61100` 电压越限事件总次数解出次数值。
- [ ] A8 控制码：`0FH`/`8FH` 帧的功能码显示为无线转发（透传）语义，数据域按 DI + 透传数据呈现。
- [ ] A9 查询页：桌面与 Web 的 DI 查询均能检索到扩展 DI（名称/单位/格式）。
- [ ] A10 两端一致性：同一帧在桌面与 Web 呈现的关键字段一致（对拍断言）。
- [ ] A11 回归：`test/test_dlt645_*.py` 全绿；`release_check.py` FAIL=0 / WARN=0。
- [ ] A12 变异反证：移除扩展 DI 分派 → A1/A6 变红；移除符号位处理 → A3 变红；移除 `0x0F` 条目 → A8 变红；删除 Web 侧同步 → A9/A10 变红。
- [ ] A13 文档转换产物入库：`.md` 与 `.docx` 一并纳入 git（参考文档随库版本化）。

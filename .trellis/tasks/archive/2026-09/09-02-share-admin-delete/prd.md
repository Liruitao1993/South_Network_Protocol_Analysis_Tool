# 管理员删除报文分享记录权限

## 需求背景

Web `/share` 报文分享页目前任何人可提交（主页「分享此帧」），但**没有删除入口**——错误/恶意/乱填的分享记录会永久堆积，页面越来越乱。

需要管理员（复用反馈管理同一套 AdminConfig 口令）删除分享记录，保持分享区内容整洁。

## 需求

1. **权限复用**：删除操作复用反馈管理页（/feedback-admin）同一套管理员口令（`admin_config.json` 的 AdminConfig，默认 admin123）。
2. **删除入口**：`/share` 页列表每行卡片在管理员登录后显示「删除」按钮，点击确认后删除该记录。
3. **删除范围**：仅删除列表可见的单条记录（按 id），不做批量删除。
4. **数据一致性**：删除后列表立即刷新（sh_load），页码/总数正确回退。

## 约束

- 未登录管理员时**不显示**删除按钮（普通浏览者看不到任何管理入口）。
- 删除为**不可恢复**操作，点击后需确认弹窗（或二次确认）。
- 不改变既有提交/搜索/分页/详情行为。
- 存储层新增 `delete(item_id)` 方法，返回是否删除成功；删除不存在的 id 应安全返回 False 而非抛错。

## 验收标准

- [ ] `/share` 页未登录时列表无删除按钮。
- [ ] 管理员登录后每行卡片出现「删除」按钮；点击弹确认；确认后该记录从列表消失。
- [ ] 删除不存在的 id 不报错（返回失败提示或静默忽略）。
- [ ] 删除后翻页/总数正确（不出现空页或总数负数）。
- [ ] GUI 分享的记录（source=gui）同样可删除。
- [ ] `test_frame_share.py` 新增删除用例并全过；`test_web_feedback`/`test_feedback_api` 回归不新增失败。
- [ ] 真机验证：/share 页管理员登录 → 删除一条 → 刷新后确认已删除。

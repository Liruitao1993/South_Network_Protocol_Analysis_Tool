# 频谱图绘制（频谱仪参数配置 + trace 数值输入 → 频谱图输出）

## Goal

GUI 新增**常驻标签页「频谱图」**：按频谱仪口径配置扫描参数（起始/终止频率、RBW/VBW、参考电平、每格 dB、单位、检波方式、纵向格数）→ 输入一条 trace 的全部扫频点数值 → 绘制仪器式网格频谱图 → 可导出 PNG。纯 QPainter 自绘，**零新增第三方依赖**。

## Requirements

### R1 频谱仪参数配置区

| 参数 | 控件 | 默认 | 校验 |
|---|---|---|---|
| 起始频率 | 数值 | 240 | > 0，且 < 终止频率 |
| 终止频率 | 数值 | 960 | > 起始频率 |
| 中心频率 | 数值（**双向联动**） | 600 | 与扫宽联动后起点必须 > 0 |
| 扫宽 Span | 数值（**双向联动**） | 720 | > 0 |
| 频率单位 | 下拉 kHz/MHz/GHz | MHz | 四个频率字段共用同一单位 |
| RBW（分辨率带宽） | 数值 + 单位下拉（kHz/MHz） | 空 | 填了必须 > 0 |
| VBW（视频带宽） | 数值 + 单位下拉（kHz/MHz） | 空 | 填了必须 > 0 |
| 参考电平 | 数值（dB） | −20 | 任意有限值 |
| 每格 dB（dB/div） | 数值 | 10 | 0.1 ≤ x ≤ 20 |
| 纵向格数 | 整数 | 8 | 4 ≤ n ≤ 12 |
| 单位 | 下拉 dBm / dBμV / dBmV | dBm | — |
| 按 50Ω 换算 | 复选框 | 不勾 | — |
| 检波方式 | 下拉 峰值/准峰值/平均值/RMS/采样 | 峰值 | 仅作图中注记 |

- **只读派生显示**（不额外输入）：中心频率 = (起+止)/2、扫宽 = 止−起、频率步进 = 扫宽/(N−1)（N=trace 点数），随输入实时刷新。
- **单位语义（明确定义，避免隐式换算）**：`单位` 下拉同时决定纵轴标注与图中注记；trace 数值按该单位**原样绘制**。勾选「按 50Ω 换算」时才做偏移（输入按 dBm 计：dBμV = dBm + 107，dBmV = dBm + 47），不勾选则数值不变、仅标注改变。

### R2 trace 数值输入（单 trace）

- 多行文本输入框；分隔符支持 空格 / 制表符 / 逗号 / 分号 / 换行，忽略首尾空白与 BOM（U+FEFF）；支持 `+`/`-` 号与科学计数法（`1.2e-3`）。
- **非法 token 必须明确报错**（含「第 N 项」与原文），**不得静默丢弃、不得清空已有图形**（遵循 AGENTS.md §8 陷阱 23「字段/数据不一致时的容错显示原则」）。
- 点数 N = 实际数值个数（不额外声明点数，频率轴按 N 线性均分）；N < 2 → 报错（无法成图）。
- 「粘贴」（读剪贴板）、「清空」按钮；状态行显示 `点数 N / 频率步进 / span / RBW`。

### R3 绘图（仪器式网格 + 自动适配切换）

- **网格**：横向固定 10 格；纵向 `纵向格数` 格；仪器式口径 = 顶格为参考电平，向下每格 −`每格 dB`。
- **「纵轴自动适配」复选框**：勾选后纵轴范围取 trace min/max 并留 5% 边距、等分 `纵向格数` 格；取消则回到参考电平口径。
- **迹线**：单条折线；N ≤ 201 时叠加数据点标记便于核对。数值超出绘区时裁剪到边缘并在状态行提示超范围点数。
- **标题与注记**：顶部标题「频谱图」+ 参数注记行（起止频率 / span / RBW / VBW / 检波方式 / 参考电平 / 每格 dB / 点数 / 单位），导出时一并渲染（形成可直接贴报告的图）。
- **频率刻度**：标签按数值自动选单位（Hz/kHz/MHz/GHz）与小数位；绘区宽度不足以放下每格标签时间隔标注（避免重叠）。
- **主题适配**：浅/暗主题下网格、文字、迹线、背景均清晰可读；暴露 `restyle_for_theme(dark)`。

### R8 MARK 标记与基础计算

- **添加**：点击绘图区在该频率处添加标记（吸附到最近数据点），依次命名 M1…M6，最多 6 个（超出给提示不添加）。
- **颜色区分**（2026-09-14 需求变更）：**每个标记一种固定颜色**（M1…M6 与序号绑定，浅/暗主题各一套），图上竖虚线/圆点/`M?` 标签与标记表行文字同色，便于在图上与表格之间一一对应；切换主题时同步重算。
- **峰值搜索**：作用对象 = 标记表中选中行（无选中则最后一个标记）。
  - 「峰值搜索」→ 该标记移到全局最大幅值点；
  - 「下一个峰值」→ 该标记移到下一个局部峰（显著度阈值 3 dB，环形，到末尾回到首个峰）；**只有一个显著峰时提示「已是唯一显著峰」不移动**；
  - 无标记时两个按钮都直接新建 M1 于峰值点。
- **删除/清空**：删除选中标记（无选中删最后一个），删除后**重新连续编号 M1..Mn**；清空后标记表隐藏。
- **显示**：标记随图渲染（竖虚线 + 圆点 + `M?` 标签）；标记表列 `标记 / 频率 / 幅值(单位) / Δ频率(哪两点) / Δ幅值(哪两点)`。
- **两点测量必须标注是哪两点**（2026-09-14 需求变更）：Δ 单元格与测量栏文案都带 `M?↔M?` 前缀（如 `M1↔M3  560.348 MHz`、`Δf(M1↔M2) 400.696 MHz  Δlevel -0.40 dB`）；`Δ 参考` 下拉可切换参考标记（默认 M1），切换后表格 Δ 列与测量栏同时按新参考重算。
- **重绘语义**：标记以**频率**为锚点；参数/单位/纵轴口径改变后重绘时按频率重新吸附，超出新扫描范围的标记丢弃（提示**追加**在点数/步进状态行之后，不覆盖）。
- **口径一致**：表单参数（单位/参考电平/每格/格数/换算/检波）改动但未点「绘制」时，只读纵轴标签追加「（参数已改，点「绘制」生效）」，避免同屏出现两套口径而看不出差别。

### R10 积分带宽（IBW）与带内积分功率

- **参数**（参数区新增「积分带宽」分组）：`中心频率`（与四字段共用频率单位）、`积分带宽`（数值 + 单位 kHz/MHz）、`显示积分带宽` 复选框（默认不勾，避免不用此项时干扰读图）；带宽必须为正数，否则报错不绘制。
- **图上显示两条竖线**：带宽边沿 = 中心频率 ± 带宽/2，画两条**点划线**（独立配色，与 6 个标记颜色都不撞色）+ 边沿之间半透明填充带 + 带内顶部标签 `IBW 550–650 MHz`。
- **积分功率**：对落在 `[低边沿, 高边沿]` 内的数据点做线性功率求和后转回 dB，并按 `频率步进 / RBW` 归一化（RBW 未填则不归一化并在读数中注明）；结果随当前幅值单位显示（dBm/dBμV/dBmV——单位偏移在求和前后相互抵消，故直接对显示值求和即可）。
- **读数位置**：参数区只读行「积分功率」+ 画布右上读数框追加一行 `IBW Σ -33.21 dBm`；同时给出带宽内点数。
- **越界处理**：带宽超出扫描范围时**按交集积分**并在读数中标注（`⚠ 超出扫描范围，按交集积分`）；与扫描范围无交集时不填充、读数提示 `⚠ 与扫描范围无交集`；竖线绘制时夹到绘图区边缘（带内标签同样夹取，不越出绘图区）。
- **口径说明**：归一化口径按实际原因显示（`按 RBW 归一化` / `未归一化，RBW 未填` / `未归一化，点数不足`）；带宽小于一个频率步进时追加 `⚠ 带宽小于频率步进，按单点外推`。
- **绘制顺序**：半透明填充与两条竖线画在**迹线之下**（区域带属背景，不压暗迹线与标记），带内 `IBW 起–止` 标签仍画在最上层；画布右上读数框用**短行** `IBW Σ -49.96 dBm`（完整口径文本留在参数区只读行），避免窄画布下压住纵轴刻度。
- **数值健壮性**：功率求和用**移位求和**（`peak + 10log10(Σ10^((v-peak)/10))`），±数千 dB 级极端电平不溢出/不下溢（直接 `10^(L/10)` 会抛 OverflowError 或 log10(0) 域错）。
- **重绘语义**：与标记一致，参数/单位/纵轴口径变化后重绘即按当前 trace 重算；`set_trace` 一并清空积分带宽（唯一写入入口是 `_refresh_integration`）；表单 RBW 改动未重绘时读数追加「（RBW 参数已改，点「绘制」生效）」。

### R11 trace 文本预处理（日志行清洗）

实际粘贴的 trace 往往带日志前缀，真实数值在**行尾**：

```
2026-09-14 12:25:43 015: 流程日志：2026-09-14 12:24:26:295 --USER--MTC@DESKTOP-417FFS5: -51.564613
```

- **逐行判定规则**（纯逻辑，可脚本测试；**规则顺序即优先级**）：
  1. 空行 / 纯分隔符行 → 忽略（不计入统计）；
  2. 该行所有 token 都是有效数值 → 全部作为数据点（保持既有行为，支持一行多值）；
  3. **含日志结构**的行（含 `:`/`：`/制表符/`YYYY-MM-DD`）：行尾能以**分隔边界**取到**电平数值**（`(?:^|空格:=：,;|>)<数值>$`，数值后可带 `dBm/dBμV/dBmV/dB`）→ 取该值（日志行清洗）；
  4. 含日志结构、行内有数值却拿不到行尾数值 → **报错**（`第 N 行含数值但行尾不是数值，无法确定 trace 值：<整行>`）——静默丢行比报错危险得多；
  5. 含日志结构且整行无数值（头部行 / 纯时间戳行）→ 跳过并计入 `skipped`；
  6. 无日志结构却含非法 token（`12a3`、`abc`、`x=12a3`）→ **报错**（`第 N 项（第 M 行）不是有效数值：<原文>`），拼写错误不被当噪声吞掉。
- **边界要求**：行尾数值前必须是分隔字符。`12a3` 的尾部 `3` 前面是字母 → 不提取 → 按第 6 条报错。
- **时间戳防护（两层）**：整行就是时间戳（`2026-09-14 12:24:26:295`）按第 5 条跳过；行尾形如 `HH:MM:SS` / `HH:MM:SS:mmm` / `HH:MM:SS.mmm`（`12:24:26`、`2026/09/14 12:24:26`）同样按第 5 条处理，**绝不把秒/毫秒当作电平**；用户真实行（行尾是 `: -51.564613`）不受影响。
- **单位白名单只含电平单位**：`Hz/MHz/GHz` 刻意不在其中——日志里「中心频率 600 MHz」这类行若被当电平会污染图形（按规则 4 报错，提示用户剔除）。
- **单位后缀仅对「含日志结构」的行生效**：裸行 `-51.5 dBm` 仍按规则 6 报错（与旧实现一致，不引入新的静默行为）。
- **统计与提示**：解析结果携带 `TraceInput(values, lines_total, lines_used, lines_skipped, log_lines)`，满足不变式 `lines_total == lines_used + lines_skipped`；发生清洗或跳过时状态行追加 `已清洗 N 行日志` / `跳过 K 行无数值`（切换「纵轴自动适配」等状态行重写路径**不得吞掉**该提示）；整份输入无任何数值时报 `请输入 trace 数值（已跳过 K 行无数值日志行）`。
- **兼容**：`parse_levels()` 对纯数值输入的判定与旧实现逐位一致（返回值 = 预处理后的数值元组），既有报错文案与序号语义不变（多出的「（第 M 行）」为附加信息）。

## Acceptance Criteria

1. 启动 GUI 后「频谱图」tab **常驻可见**，切换任意协议（0~11）都不隐藏。
2. 参数填 起始 240 MHz / 终止 960 MHz / RBW 100 kHz / 参考电平 −20 dB / 每格 10 dB / 8 格，粘贴 N=100 个数值 → 图形出现：X 轴左端标 `240 MHz`、右端标 `960 MHz`；Y 轴顶端标 `-20`，每格递减 10；状态行显示 `点数 100`、`频率步进 7.27273 MHz`（= 720/99）。
3. trace 文本含非法 token（如 `12a3`）→ 状态行给出含序号/原文的错误，且不绘制错误图形、不崩溃。
4. 勾选「纵轴自动适配」后纵轴刻度改为数据范围（含 5% 边距），取消勾选后恢复参考电平口径。
5. 单位选 `dBμV` 且勾选 50Ω 换算 → 迹线与注记按 +107 偏移；不勾选 → 数值不变仅轴标注改变。
6. 点「导出 PNG」生成 PNG，`QImage` 可读回且尺寸 > 0，图像包含标题与参数注记。
7. 切暗色主题后网格/文字/迹线仍清晰（offscreen 断言颜色随主题变化且无异常）。
8. `python test/test_spectrum_model.py` 与 `python test/test_spectrum_gui.py` 全过；`python release_check.py` 无 FAIL。
9. 鼠标在绘图区移动 → 出现十字虚线与读数框，读数等于最近数据点的频率与幅值；移出绘图区后十字与读数消失。
10. 在绘图区点击 3 次 → 标记表出现 3 行（M1/M2/M3），各行频率与点击位置对应的数据点频率一致；**三行文字颜色互不相同且等于 `marker_color(主题, 序号)`**；Δ 列带 `M?↔M?` 前缀（M2 行 `M1↔M2 …`、M3 行 `M1↔M3 …`）；`Δf(M1↔M2)` 文本 = 两点频率差（±1 个频率步进内）。
11. 「峰值搜索」把标记移到最大幅值点（该行频率 = 峰值频率）；「下一个峰值」移到下一个局部峰；「清空标记」后标记表隐藏、图上标记消失；**选中某行时按钮作用于该行**；删除中间标记后剩余标记连续编号 `M1..Mn`。
12. 带标记导出 PNG 的像素与无标记导出不同（标记与 Δ 注记确实渲染进图）。
13. 第 7 个标记被拒绝并提示「最多 6 个标记」。
14. 切换 `Δ 参考` 为 M2 → 表格 Δ 列与测量栏同时改为 `M2↔M1` / `M2↔M3` 口径。
15. 收窄扫描范围重绘 → 越界标记被丢弃，状态行**同时**包含「已丢弃」与「点数 N」信息。
16. 只改表单参数（如单位）不点「绘制」→ 纵轴标签追加「（参数已改，点「绘制」生效）」，画布口径不变；改回后提示消失。
17. `peak_indices` 在 16000 点整体下降型频谱上 < 50 ms（原逐点扫描实现 3.7 s），保证「下一个峰值」不冻结界面。
18. 勾选「显示积分带宽」，中心 600 MHz、带宽 100 MHz → 图上出现两条竖线，位置分别对应 550 MHz 与 650 MHz 的网格横坐标（±1 像素），两线之间有半透明填充带，带内顶部标签为 `IBW 550–650 MHz`。
19. 101 点常量 trace（每点 −70 dBm、步进 7.2 MHz）在带宽 720 MHz、RBW 7.2 MHz 下 → 积分功率 = −70 + 10·log10(101) = **−49.96 dBm**（读数文本含该值、含「101 点」与「按 RBW 归一化」）。
20. RBW 留空 → 读数标注「未归一化」；积分功率 = −70 + 10·log10(101) 的未归一化值，且与上一条（归一化）一致（本例步进 == RBW）。
21. 带宽超出扫描范围（中心 240 MHz、带宽 400 MHz）→ 读数含「超出扫描范围」，仍给出按交集计算的值；带宽与扫描范围无交集（如中心 5 GHz）→ 读数含「无交集」且不填充。
22. 积分带宽关闭或未绘制 trace → 图与基线渲染逐像素一致（无竖线、无填充）；且**同一 trace 下「从未开启」与「开启后再关闭」逐像素一致**。
23. 极端电平（±1e308 与 −4000 dB）不抛异常且积分功率有限（移位求和）；−4000 dB 两点全带宽结果 = 电平 + 10·log10(2) + 归一化增益（±1e-9）。
24. 带宽小于一个频率步进（如带宽 1 MHz、步进 7.2 MHz）→ 带内 1 点、读数含「按单点外推」；`RBW=0` 与「单点 trace（无步进）」的未归一化原因分别显示为「RBW 未填」「点数不足」。
25. 半透明填充与竖线画在迹线之下（带内迹线像素不被压暗），带内标签夹在绘图区内（窄带靠右缘时不越出 plot.right()）。
26. 粘贴用户格式的日志行 `2026-09-14 12:25:43 015: 流程日志：2026-09-14 12:24:26:295 --USER--MTC@DESKTOP-417FFS5: -51.564613`（多行）→ 提取到的数值依次为各行的行尾数值（`-51.564613` 等），点数 = 行数，状态行出现「已清洗 N 行日志」。
27. 混合输入（若干行纯数值 + 若干行日志 + 若干行无值头部如 `流程日志：开始采集`）→ 数值按出现顺序提取，跳过行数被统计并提示；纯时间戳行不产生数值。
28. 兼容性不回归：`12a3`、`abc`、`x=12a3`、`12a3 5` 仍报 `第 N 项不是有效数值`；`1 2,3;4` 仍返回 4 个值；纯分隔符输入仍报「请输入 trace 数值」。
29. 时间戳防护：仅含时间戳的行（`2026-09-14 12:24:26:295`、`12:24:26`、`2026/09/14 12:24:26`、用户格式表头行）**不产生任何数值**（跳过计数）；行尾是真值的用户格式行仍取到真值。
30. 规则优先级：含日志结构且行内有数值、但行尾非数值（`… INFO: -51.5 dBm extra`、`… 设置中心频率 600 MHz`）→ **报错并指出行号**（不静默丢行）；行尾 `1e999`（非有限）同样报错，不进入 levels。
31. 清洗提示不丢失：切换/取消「纵轴自动适配」后状态行仍保留「已清洗 N 行日志」。
32. 统计不变式：`lines_total == lines_used + lines_skipped`；全无值输入报错信息携带跳过行数。

## Out of Scope

- 多 trace 叠加（Trace A/B/C）、迹线数学（A−B）、平均/最大保持/最小保持。
- CSV / Excel / 剪贴板导出（范围问答未勾选）。
- 实时数据接入（串口、监控器、SCPI 仪器控制）——本期仅手工输入；绘图入口按数据无关设计，后续接数据源不需重构。
- 峰值自动搜索与标记、游标（marker）读数、上下限线、对数频率轴、时间瀑布图。**（2026-09-14 需求变更：光标读数、MARK 点、两点 Δ 测量、峰值搜索已纳入 R7/R8；仍不做插值光标、迹线数学、限值线、占用带宽 OBW、统计量（均值/标准差））**
- 频谱数据解析（从设备日志/报文中提取 trace）——本期只接受数值列表。
- Reflex Web 版同步（后续独立任务）。

## Risks / Deferred

- **纵向格数默认 8** 取自常见手持/台式频谱仪屏幕口径；不同型号为 8 或 10 → 已用参数暴露，不写死。
- **50Ω 换算常数**（+107 / +47）仅对 50Ω 系统成立；75Ω 系统需另加换算（本期不做，注记中标注 50Ω）。
- **1:1 复刻某型号屏幕**需该型号截图作 golden；本期按通用仪器口径绘制，不声称与某型号一致。
- **超大点数（>100k）**未做抽样优化（QPainter 折线本身支持），如遇性能问题另开任务。
- **PNG 导出**依据原始需求「输出一个绘制好的频谱图」纳入；若评审认为超范围，直接删该按钮与 R4（不影响其余交付）。

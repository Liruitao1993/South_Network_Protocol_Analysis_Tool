# PRD：协议7「协议测试」页（AFN/Fn 分类树 + 扩展命令）

## 背景与用户原话

> 「在协议7下，也开发一个协议测试页面，可以参考协议8下的协议测试页面设计，但是所使用的协议是7，
> 开发的时候需要非常的全面，有分类树，涉及到扩展命令也一并设计进去。」

协议8（698.45）已有「协议测试」页（`dlt698_test_core.py` + `dlt698_test_widget.py`，按 OAD 分类的预置库）。
协议7（国网 Q/GDW 10376.2—2024）的现场高频操作是「按 AFN+Fn 下发某条命令、看模块应答」，
组帧页要手选 AFN/Fn 并填一堆字段，效率低。本任务新增一个自足的预置命令树页面。

## 目标（必须全部达成）

1. **分类树（按 AFN / Fn）**：
   - 顶层 = AFN 功能类（`00H 确认/否认` … `15H 文件传输`、`50H~56H 福建增补`、`F0H 内部调试`、`F1H 并发抄表`）；
   - 叶子 = **具体 (AFN, Fn) 命令**（如 `03H F1 厂商代码和版本信息`），叶子数量 = schema 覆盖的全部命令；
   - 树节点文案同时给出十六进制 `AFN/Fn`、中文名，并能区分「标准 / 福建增补 / 扩展 / 自定义」来源。
2. **页面分页**（与 698 页「按服务类型分页」同构）：
   - 「读取数据」：查询类 AFN（03H / 04H / 10H / 14H / 53H / F0H）
   - 「设置控制」：设置/控制类 AFN（01H / 02H / 05H / 11H / 12H / 13H / 15H / 51H / 52H / 55H / F1H）
   - 「主动上报」：上行应答/上报类 AFN（00H / 06H / 50H / 56H）
   - 「EB 扩展」：附件1 本地通信模块扩展 EB 数据标识（75 条），按功能分组，构造 645 帧（DI+数据，+0x33 加扰）并可选择外层用 `AFN=02H F1` 转发帧下发
   - 「自定义」：读取 `gdw_custom_afn.json` 的用户自定义 AFN+Fn（有则列出、可下发；无则给空态说明）
3. **动态参数表单**：按 `GDW_AFNFN_SCHEMA[(afn,fn)]["fields"]` 自动生成控件，支持 schema 现有全部类型
   （`bcd` / `bytes` / `enum` / `uint8` / `uint16`（含 endian/length_field）/ `list`（count_field + item_fields）），
   组帧一律走 `GDWFrameGenerator.generate_frame(...)`（**唯一实现，不手拼帧**）。
4. **报文配置**：通信模块标识 / 中继级别 / 中继地址 / 源地址 A1 / 目的地址 A3 / 报文序列号 / 通信速率 /
   预计应答字节数；福建增补帧按生成器既有规则（保留 5B + 序号，地址固定 A1+A3）。
5. **响应判定（不冒充成功）**：
   - 结构/校验：帧长自证 + CS；
   - AFN/Fn 回显必须与请求一致（否则标记「非本命令响应」并忽略）；
   - `00H` 确认/否认：确认=成功，否认=失败（给出错误代码说明）；
   - 其他命令：解析 `错误代码`/`确认标志` 字段；无字段可判时给 `ok=None` + 「未做字段级判定」，**不得写成功**。
6. **发送队列**：勾选多条叶子按顺序下发、等应答再发下一条；超时重试、停止、单条失败不中断整批（记失败并继续）；发送中禁止修改参数。
7. **通道**：复用 `channel_link.ChannelController`（串口 / 蓝牙），整帧一次 ATT 写、超限报错不发送；蓝牙连接归「蓝牙工具」页。
8. **详情展示**：信息表（逐字段）+ 报文表（整帧，双击送单帧解析）；收发日志（彩色、可折叠）。
9. **持久化**：`gdw_testbench.json`（地址/序号/通道/超时/重试/勾选的书签/窗口分栏），原子写、坏文件宽容。
10. **接线与显隐**：`protocol_registry` 新增能力位 `has_gdw_test`（仅协议7）；tab 文案「协议测试」；
    懒加载、主题钩子、退出 cleanup、共享串口注入；协议8/6 既有页面行为不变。

## 非目标

- 不做自动轮询 / 定时任务（属测试方案页）。
- 不做 EB 数据内容的「业务含义」二次解释（解析侧已有 `_parse_eb_di`；本页只给原始/字段级 hex 回显）。
- 不改 `gdw_frame_generator_schema` / 解析器判据；只消费。

## 验收标准

- [ ] 分类树总数 = `GDW_AFNFN_SCHEMA` 命令数 + EB 条数 + 自定义条数（测试断言三者与单一来源逐条对拍）。
- [ ] 每个 AFN 只归属一个页面（测试断言无遗漏、无重复）；福建增补/扩展命令都在树里可点。
- [ ] 随机抽取若干命令：组帧 → 本仓解析器回读，AFN/Fn/字段值一致；`00H`/`05H F1` 等含字段命令逐字节断言。
- [ ] EB 页：读/写两类 645 帧逐字节断言（DI 低字节在前、数据域 +0x33、CS），转发模式下外层 AFN=02H F1 长度字段自洽。
- [ ] 判定矩阵：确认/否认、错误代码、AFN 不符、Fn 不符、CS 错、截断 —— 各自的 `ok/reason` 断言。
- [ ] offscreen GUI：五页切换、树筛选、勾选顺序下发、超时重试、停止、落盘重开、主题、cleanup、几何零重叠/按钮不裁字。
- [ ] `release_check.py` 里相关测试全绿；变异反证：AFN 回显判定、EB 加扰、发送队列 `_awaiting` 守卫、前导 FE 重同步各至少 1 条变红后还原。

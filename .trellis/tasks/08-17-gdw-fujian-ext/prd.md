# PRD：协议7（国网）新增福建增补（AFN 50H~56H）+ 本地通信模块扩展（EB数据标识）解析与组帧

## 背景

用户提供 `协议文档/7.国网本地接口协议/` 下 3 份新协议文档（已转换 markdown）：
- **附件1**：`本地通信模块扩展协议V3.31-20241205`（1425 行）— 通信模块（CCO/STA）EBXXXXXX 数据标识扩展（645/698 承载），含事件管理、台区识别、设备基础信息、时钟管理、档案管理、任务队列等
- **附件3**：`1376.2集中器本地通信模块接口协议【福建增补】V1.4-20240729`（1597 行）— 376.2 福建增补规约，**AFN=50H~56H** 新功能码（确认/初始化/数据转发/查询/控制/主动上报），与国网标准并存
- **附件4**：`集中器和CCO通信接口补充要求-20220416`（短，以太网/UDP 通信接口补充）

现有协议7（国网 Q/GDW 10376.2—2024）解析器 `gdw10376_parser.py`、组帧库 `gdw_send_frame_lib.py`、schema `gdw_frame_generator_schema.py`、校验器 `validator/gdw_validator.py` **均未覆盖福建增补**。

## 目标

确保协议7解析器可以解析新增协议（附件1 EB 数据标识 + 附件3 AFN 50H~56H），同时具备组帧功能。

## 需求

- [x] 识别 376.2 福建增补帧（AFN ∈ {50H,51H,52H,53H,55H,56H} 或符合福建增补信息域特征）
- [ ] 正确解析福建增补信息域 R（下行：保留5+序列号1=6B；上行：保留4+事件标志BS1+序列号1=6B）
- [ ] 正确解析福建增补地址域 A（A1+A3=12B，无中继 A2）
- [ ] 保留现有 2024 国网帧的解析能力（向后兼容，不破坏）

### R2 福建增补各 AFN/Fn 数据单元解析（附件3）

- [ ] AFN=56H：主动上报 — F1~F6/F13~F15（主动注册/事件内容/抄读请求/响应报文/信道延时/广播完成/带任务信息事件上报）

## 验收标准

1. `python test/test_gdw_fujian.py` 全部断言通过
2. 解析附件3 各 AFN 帧时表格字段命名遵循 §4.2（`原始值`/`十进制`/`解析值`/`说明`/`偏移`/`长度`）
3. 解析附件1 EB 帧（645 结构）时能正确显示数据标识名称与数据内容
4. 福建增补组帧生成字节与文档示例一致（校验和/结构）
5. 现有国网协议7 帧解析与组帧回归不破坏（人工抽查 + 无既有测试回归）
6. GUI：协议7 下拉解析福建增补帧显示完整字段；组帧页可选福建增补 AFN/Fn；查询页可见新 AFN+Fn 与 EB 数据标识
7. 文档同步：CHANGELOG（main_gui.py）、AGENTS.md §10/§11、README 更新

## 非目标

- 698.45 映射（EB55XXXX 功能映射）完整实现——先支持 645 承载 + 数据标识识别，698 映射作为后续

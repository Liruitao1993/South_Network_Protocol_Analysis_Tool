# PRD：国网协议 7 组帧 GUI 测试与修复

## 背景

GUI 版本（`main_gui.py`）支持协议 7（国网协议 Q/GDW 10376.2-2024）的组帧功能。用户要求全面测试该功能中的所有 GUI 问题，并修复发现的缺陷。

## 目标

通过系统化测试，发现协议 7 组帧功能在 GUI 交互、输入校验、结果展示等方面的所有问题，并逐一修复。

## 范围

- 协议 7 组帧标签页的所有 UI 组件
- 输入字段（地址、信息域、功能码、数据域等）
- 预设命令按钮
- 生成结果展示与复制
- 与 GUI 其他标签页的交互影响
- 不改动协议解析逻辑本身，只修复 GUI 层问题

## 验收标准

1. 协议 7 组帧页面所有输入字段可正常输入并生效。
2. 组帧结果与预期一致，无崩溃或异常。
3. 常见异常输入有合理提示，而非报错或卡死。
4. 预设命令按钮正确填充字段并生成帧。
5. 生成的帧可复制或用于单帧解析。
6. 不影响其他协议组帧功能。

## 非目标

- 不修改国网协议底层解析器 `gdw10376_parser.py`。
- 不新增协议支持。
- 不重构整个组帧系统架构（除非必要）。

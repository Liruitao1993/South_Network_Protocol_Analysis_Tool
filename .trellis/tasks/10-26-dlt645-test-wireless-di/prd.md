# 645 协议测试页：接入无线模组接口手册 V1.6 扩展 DI

## Goal

用户：「@南网光伏协议转换单元无线接口手册-V1.6.pdf 在 645 的协议测试页面里，功能列表树没有包含这个文档中的协议扩展，我需要你实现」。

**定位结论**：645 测试页的分类树来自 `dlt645_pv_ext.merge_pv_di_map`（基础 `dlt645_di.json` 1099 +
附件1 的 `02E6/03E6/04E6` 682），而这份**无线模组接口手册 V1.6** 的 12 条 DI 定义在
`dlt645_pv_wireless.WIRELESS_DI_MAP`（组帧页已接、测试页没接）：

| 分组（手册） | DI | 名称 |
|---|---|---|
| 数据转发 | `02EB0000` | 光伏逆变器数据转发（请求带 `Z|C|T|DATA`） |
| 无线参数 | `04E60001` / `04E60002` | 下挂逆变器地址列表 / 无线频段信息 |
| 拓扑 | `04900100` | 模组组网拓扑信息 |
| 升级 | `04900101`~`04900106` | 块状态字 / 升级状态 / 文件信息 / 块数据 / 最大块大小 / 执行升级时间 |
| 版本 | `04900107` | 无线模组版本信息 |
| 在网状态 | `028100FF` | 无线模组在网状态（手册口径：`1EH` 上报 / `9EH` 确认） |

现有可用能力（**全部复用**）：`dlt645_pv_wireless_frame` 的 `wireless_di_info` /
`build_wireless_fields` / `build_wireless_payload` / `wireless_request_extra` / `REQ_WITH_PAYLOAD_DI`；
`dlt645_pv_wireless.parse_wireless_di` 的逐字段解码；`dlt645_frame_schema.build_di_fields` 对
无线 DI **优先分派**；组帧仍走 `DLT645FrameGenerator`。

## Requirements

### R1 分类库（`dlt645_test_core`）

- R1.1 `catalog()` 末尾新增顶层分类 **「光伏无线扩展（V1.6）」**；子类 = 手册 `group`
  （数据转发 / 无线参数 / 拓扑 / 升级 / 版本 / 在网状态，按 `WIRELESS_DI_MAP` 插入顺序）；
  叶子 = 12 条 DI。**数据全部取自 `WIRELESS_DI_MAP`（单一来源），不手写名称/格式**。
- R1.2 `DiItem` 增 `wireless: bool = False` 与 `note: str = ""`（手册备注，用于读页说明）；
  长度 `-1`（不定长）统一归一为 `0`（与既有 `length=0` 的展示口径一致）。
- R1.3 `di_info()` 在基础/扩展表查不到时回落 `wireless_di_info()`（供响应解码与写页字段用）。
- R1.4 叶子总数 1765 → **1776**（12 条无线 DI，其中 `04E60001` 与附件1 重叠、以无线手册为准，
  只挂在无线分类；光伏参数 172 → 171）；`find_di/filter_items/item_count` 自动覆盖。

### R2 读请求参数（核心，否则 02EB0000 组不出合法帧）

- R2.1 新 `read_request_fields(di) -> List[dict]`：仅对**读请求需要携带数据域**的 DI 返回字段——
  `REQ_WITH_PAYLOAD_DI`（当前 `02EB0000`）与 `FF00DD01`（LME 条目）；
  字段定义取 `build_di_fields(di)`（与组帧页同源）。其余 DI 返回空列表。
- R2.2 `build_read(di, addr, field_values=None)`：把字段值并入 `fv`（`数据标识 DI` 强制覆盖）；
  不传时行为与现在逐字节一致。
- R2.3 响应摘要/取值：`evaluate_response(kind="read")` 对无线 DI 用
  `parse_wireless_di(di, ctrl, logical_data)` 的行解码，摘要取前 3 个 `└` 字段
  `名称=解析值`；无行/解码失败回落 HEX。`detail_lines` 已由解析器覆盖（不重复实现）。

### R3 特殊命令（读不了的直连动作）

- R3.1 `command_groups()` 末尾新增分组 **「无线扩展（V1.6）」**，包含 schema 已有的
  `0x06`（上报确认应答（无线））与 `0x1E`（在网状态上报（无线））；字段仍取 schema。

### R4 页面（`dlt645_test_widget`）

- R4.1 读数据页「当前项」：当 `read_request_fields(di)` 非空时渲染动态字段（与写数据页同款），
  帧预览与 `_build_queue` 把字段值传入 `build_read`；无线 DI 追加一行**手册备注**（`note`），
  例如 `028100FF` 注明「手册口径 1EH 上报 / 9EH 确认，11H 读请求设备可能不应答」。
- R4.2 写数据页无需改（`build_di_fields` 已对无线 DI 分派）。
- R4.3 树文案/统计自动跟随；切页/筛选行为不变。

### R5 测试

- R5.1 分类：顶层 11 类、无线分组 6 个/12 叶子、名称与 `WIRELESS_DI_MAP` 逐条一致、
  叶子唯一（1776）、`04E60001` 只在无线分类、`find_di("04900107")`。
- R5.2 组帧黄金：`04900107` 读 → `68 … 68 11 04 <DI 低字节在前> CS 16`；
  `02EB0000` 读（Z=08/C=02/T=10/DATA=681100）→ 逻辑数据 = DI + `08 02 10 68 11 00`；
  `04900105` 写（241）→ 14H 数据域含 `F1 00`；`028100FF` 读只带 DI。
- R5.3 判定：喂 `04900107` 的 91H 应答（ASCII `V1.2.3`）→ 成功且摘要/值含版本串；
  `04E60002` 应答摘要含调制/信道。
- R5.4 命令：分组含 06H/1EH，组帧控制码正确。
- R5.5 GUI（offscreen）：读页选 `04900107` 预览 11 04；选 `02EB0000` 出现 4 个请求字段且预览
  长度随字段变化；选 `028100FF` 说明含 `1EH`；特殊命令页树 6 组且含「在网状态」。
- R5.6 变异反证：① `read_request_fields` 恒空 → 02EB0000 帧缺少参数（红）；
  ② 无线解码分支去掉 → 摘要退化 HEX（红）；③ 分类不追加无线组 → 分类断言（红）。

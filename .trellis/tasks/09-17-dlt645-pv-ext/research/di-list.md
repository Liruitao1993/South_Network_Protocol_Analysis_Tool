## 4. 语义规则（文档出处）

- **功率符号位**：文档 §D.1（一）02E603xx/02E604xx 备注「最高比特用0/1表示正负，0为正表示逆变器发电，1为负表示逆变器用电。如最高X为0111，表示+7；X为1111，表示-7，瞬时有功功率取值范围[-7999.9999,7999.9999]」
  ⇒ 最高半字节 = 符号位(bit3) + 3 位数值，故最大值 7999.9999；BCD 低字节在前 ⇒ 最高半字节在**线序最后一字节的高 4 位**。
- **单相设备**：表下注「抄读单相设备数据块时，A相显示单相数据，B、C两项数据显示FF」
- **逐逆变器字节序**：§D.1（三）「从左往右每个字节分别表示光伏逆变器12、11、…、2、1」
- **调控结果枚举**：00 调控成功 / 01 未调 / 02 调控失败 / 03 调控不支持 / 04 其他问题（FF 不存在该项信息）
- **DI0 双语义**：变量类/参数类 = 逆变器序号（01~0C→1~12，FF=下挂所有）；事件记录类 = 第 N 次（01~32→第1~50次，0x32=50）

## 6. 附录 I.3.3.1（0FH / 8FH 无线转发透传）

- 主站请求：控制码 `0FH`，`L = 04H + 数据长度`，数据域 = 数据标识(D0~D3) + 数据(N0~Nm)
- 从站应答：控制码 `8FH`（D7=1 + 功能码 0FH），数据域同上
- 与 645 其他功能码一致：数据域逐字节 +0x33 后入帧，`-0x33` 后解析
- 实现：`dlt645_data_codec.FUNC_NAMES[0x0F] = "无线转发(透传)"`；解析器 `dlt645_parser` 新增 `func == 0x0F` 分支呈现「透传数据标识 DI」+「透传数据」，命中扩展 DI 时二次展开

# PRD：Reflex 版本浏览器自动化测试

## 背景

Reflex Web 版本已支持单帧解析、批量解析、协议组帧、报文对比、查询、报文工具等功能。需要建立浏览器自动化测试，确保主要功能在 Web 端可正常工作。

## 目标

为 Reflex Web 版本建立一套浏览器自动化测试脚本，覆盖核心用户流程，能够在本地启动 Reflex 后自动验证。

## 范围

- 使用 Playwright（Python）作为浏览器自动化工具。
- 覆盖页面：首页、单帧解析、批量解析、协议组帧、报文对比、查询、报文工具。
- 每个标签页至少验证：页面可加载、核心交互可用、无控制台报错。
- 重点验证刚移植的“报文工具”功能。
- 测试脚本应可独立运行，并能自动启动/停止 Reflex 应用。

## 验收标准

1. 测试脚本可在本地运行，自动启动 Reflex 并执行测试。
2. 单帧解析：输入 hex，点击解析，结果表格有数据。
3. 批量解析：输入多行 hex，点击解析，显示结果。
4. 协议组帧：选择协议 7/8，选择命令，生成帧。
5. 报文对比：输入两段 hex，显示差异。
6. 查询：输入关键词，显示结果。
7. 报文工具：输入 hex，执行转换，输出正确。
8. 所有测试通过时控制台无 error 级别错误。

## 非目标

- 不测试串口、TUI、GUI、Streamlit。
- 不测试 Reflex 应用本身的部署和打包。
- 不做性能测试和压力测试。

## 二、改了什么

1. **主界面右上角新增外观按钮**（太阳 / 月亮 / 显示器）
   - 位置：菜单栏右上角，顶栏折叠按钮左边；点击循环 `浅色 → 深色 → 跟随系统`。
   - 图标随**实际效果**变化：深色=月亮、浅色=太阳、跟随系统=显示器；提示写清当前模式。
   - 选择存 `config.json` 的 `ui.appearance`，重开保持；旧配置没有这个键时按原主题推断（暗色主题→深色）。

2. **7 套主题都能切深浅**（这是你要求的重点）

   | 主题 | 深色时怎么渲染 |
   |------|----------------|
   | 默认（浅色）/ 毛玻璃 / 云母 | 没有独立暗色 QSS → 用「Fusion 暗色」渲染（主题对话框已写明） |
   | Fusion 经典 / Windows 原生 / Windows Vista | **保留主题风格**，换深色调色板（`#202225` 底 + 浅色文字）+ 叠加暗色 QSS；切回浅色恢复出厂调色板 |
   | Fusion 暗色 | 永远深色；若模式是浅色，点一下自动回「默认（浅色）」 |

3. **跟随系统**：监听 `QStyleHints.colorSchemeChanged`，系统切深浅时实时跟随（只影响「跟随系统」模式）。

4. **修掉两个体验坑**：
   - 「Fusion 暗色」主题 + 浅色模式下点按钮原来没反应 → 现在自动回默认浅色；
   - 毛玻璃主题切深色时会把 `opacity=60` 当整窗透明（整页发灰发透）→ 深色一律整窗不透明。

## 四、怎么用

- 点右上角太阳：浅色 → 深色 → 跟随系统 → 浅色，循环。
- 「配置 → 主题与字体…」仍然只管主题预设与字号；外观与主题是两件事，互不覆盖。
- 想让毛玻璃/云母也有独立暗色皮肤，需要为它们各写一套暗色 QSS（工作量较大，当前用 Fusion 暗色替代）。

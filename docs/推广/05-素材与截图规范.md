# 素材规范：截图、GIF、封面

> 目的：让所有对外素材风格统一，且**必须真实**。
> 仓库历史上就吃过亏：README 里 5 张截图的中文全是方块（□），访客一眼判定「半成品」。

---

## 一、铁律

1. **必须是真实运行界面截出来的图。**
   不要用 PIL / canvas 之类"画"一个界面出来 —— 中文字体缺失时整屏会变成 `□`，而且一旦被发现是假的，
   在这个小圈子里信誉直接归零。
2. **不要 P 掉解析结果。** 可以裁切、可以加标注框，但不许改字段值。
3. **不要出现真实客户信息。** 表地址、MAC、台体编号一律用测试值（如 `000000000001`）。
4. **主题统一用深色。** 深色在视频和社交卡片里对比度更高。

## 二、怎么重新生成截图（已脚本化）

```bash
# 需要：本机 Windows + 已装 pyside6 / crcmod / pillow
python tools/capture_readme_shots.py            # 抓单帧解析 + 批量解析
python tools/capture_readme_shots.py single     # 只抓单帧解析
python tools/capture_readme_shots.py batch      # 只抓批量解析
```

原理：脚本直接构造 `MainWindow`，用仓库自带的组帧器生成**合法**报文（HCS/FCS 由生成器计算，
保证校验栏显示「通过」），灌进输入框调用真实 `parse_single()`，最后用 `QWidget.grab()` 存图。
产物写到 `docs/images/_shot_*.png`，人工挑选后改名覆盖 `readme-*.png`。

**为什么不用屏幕截图工具？**
`grab()` 不受窗口遮挡、缩放、DPI 影响，同一脚本在任何机器上产出同一张图，可以进版本库复现。

### 修改示例报文

脚本顶部三个常量：

```python
_SA = bytes([0x01, 0x00, 0x01])          # 地址特征 + 地址
SINGLE_FRAME = _get_frame(bytes([0x20, 0x0F, 0x02, 0x00]), 0x60)   # OAD = 电网频率
BATCH_FRAMES = [...]                      # 批量页的 3 条帧
```

OAD 换成别的会得到不同"人话"结果，例如：

| OAD | 解析出来是什么 |
| --- | --- |
| `20 0F 02 00` | 电网频率 · 数值 · 全部内容 |
| `20 0F 03 00` | 电网频率 · 单位 |
| `40 00 02 01` | 日期时间相关 |

## 三、需要你录的 GIF（唯一需要手工的素材）

**为什么必须要有：** 静态图证明「有界面」，GIF 证明「真的能跑」。首屏 GIF 是转化率最高的单个素材。

要求：

| 项目 | 要求 |
| --- | --- |
| 时长 | **8–15 秒**，循环播放 |
| 尺寸 | 宽 1200–1400 px，高度按窗口比例 |
| 帧率 | 15–20 fps（文件别超过 6 MB） |
| 内容 | ① 粘贴 hex ② 按回车 ③ 表格展开 ④ 鼠标点一行，左边字节高亮 |
| 工具 | ScreenToGif（Windows，免费）或 LICEcap |
| 命名 | `docs/images/demo.gif` |

录完后把文件名告诉我，我加到 README 首屏（在 `## 下载` 之前）。

> 如果 GitHub 上 GIF 加载慢，可以同时上传到 `docs/images/demo.mp4` 并在 README 里用
> `<video src="..." autoplay loop muted>` 兜底。

## 四、社交预览图

```bash
python tools/gen_og_image.py
```

产出 `docs/images/og-social.png`（1280×640），需要上传到：
**仓库 Settings → Social preview → Upload an image**

它决定分享到知乎 / 微信 / 掘金 / Twitter 时的卡片头图。没设置时 GitHub 会随机截一段页面，
通常是白底代码，很难看。

---

## 五、配图裁剪建议

| 用途 | 用哪张 | 怎么裁 |
| --- | --- | --- |
| 知乎/公众号正文 | `readme-single-frame.png` | 保留完整表格（从起始符到结束符），可裁掉顶部工具栏 |
| 社交卡片 | `og-social.png` | 不要裁，1280×640 整张上传 |
| 视频封面 | `readme-single-frame.png` | 只取中间 6–8 行，放大到占封面下半屏 |
| 群内转发 | `demo.gif` | 原样 |

**注意**：裁图后如果只剩半截表格（比如把「字段」列裁掉了），读者看不出在表达什么，
宁可不裁。

## 六、检查清单（发任何素材前过一遍）

- [ ] 中文全部正常显示，没有 `□` / 乱码
- [ ] 校验栏是「通过」，不是「失败」或空白
- [ ] 没有真实客户地址 / MAC / 设备编号
- [ ] 窗口边缘完整，没有被切掉按钮
- [ ] 深色主题，字号在手机上看仍可读
- [ ] 图片不是用脚本"画"出来的假界面

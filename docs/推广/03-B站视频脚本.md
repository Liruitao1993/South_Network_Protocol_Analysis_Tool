## 分镜脚本

### 0:00–0:12 钩子（不要片头动画）

| 画面 | 口播 |
| --- | --- |
| 直接全屏录屏：一段 hex 粘贴进去，按回车，表格刷出来 | 「先看这个。一条 698.45 报文，粘进去，按回车 ——」 |
| 镜头推近表格，鼠标点在「OAD」那一行，左边输入框对应字节高亮 | 「每个字段是什么、校验过没过，全在这张表里。」 |

> 关键：不要"大家好我是xx"。第一句话就要有画面。

### 0:12–0:45 痛点（30 秒，别超过）

| 画面 | 口播 |
| --- | --- |
| 协议 PDF 翻页、密密麻麻的字段表 | 「以前看一条报文是这样的：翻文档、找字段表、一个字节一个字节对偏移。」 |
| 计算器敲 CRC | 「然后拿计算器算 CRC。一条十分钟。」 |
| 切回工具界面 | 「现在，一条十秒。」 |

### 0:45–1:40 功能演示（核心，每段只讲一件事）

**① 单帧解析（0:45–1:05）**
- 操作：选协议 → 粘贴 → 回车
- 鼠标依次划过：起始符、长度域、控制域、地址域、HCS、APDU、FCS
- 口播：「点任意一行，左边对应的字节会亮。校验这一栏直接给结论：通过、失败，或者**未填充**。」

**② 批量解析（1:05–1:25）**
- 操作：直接贴一整段串口日志（混杂着打印信息）→ 点「开始批量解析」
- 强调：**自动从垃圾文本里把完整帧挑出来**
- 「左边是摘要，右边是选中帧的详情。导出 Excel 一列就是一条。」

**③ 组帧 + 仿照报文（1:25–1:40）**
- 操作：粘贴一条现成报文 → 点「仿照报文」→ 参数自动回填 → 改一个地址 → 校验自动重算
- 口播：「不用记字段，粘一条类似的帧，它把参数全填好。」

### 1:40–2:10 两个"别人没有"的细节

**① 「未填充」不是「校验失败」（1:40–1:55）**
- 画面：校验栏显示「⚠ 未填充」
- 口播：「台体日志里 HCS、FCS 经常是全 0，因为要等硬件发射时才填。这时候它报的是'未填充'，不是'校验失败'。这俩的区别，踩过坑的都懂。」

**② 15 种协议（1:55–2:10）**
- 操作：展开协议下拉框，快速滚一遍
- 口播：「南网、国网、698.45、645、DLMS/HDLC、新一代载波、国网双模、HDC 1.0……一共 15 种。」

### 2:10–2:35 其他能力（快剪，一句一个）

- 串口 / 蓝牙收发（3 秒）
- 通信时序图一键成图（3 秒）
- 报文对比，字段级 diff（3 秒）
- 光伏升级：升级前后自动比对版本（3 秒）

口播：「串口、蓝牙、时序图、报文对比、升级……都在同一个窗口里。」

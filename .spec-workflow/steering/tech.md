# 技术约束

## 项目类型
桌面应用 + Web 应用 + TUI 终端应用，三端并行的协议解析工具。

## 核心技术栈

### 主要语言
- **Python 3.8+**：纯 Python 实现，无构建系统
- **运行环境**：Windows 优先，需保证 UTF-8/GBK 编码兼容

### 关键依赖
- **PySide6**：GUI 主界面框架（主程序 `main_gui.py`）
- **NiceGUI**：Web 界面框架（`web_app.py`，1.8.2 新增）
- **Textual**：TUI 终端框架（`tui_app.py`，可选）
- **crcmod**：CRC 校验计算（698.45 协议必需）
- **lupa**：Lua 脚本引擎（测试计划，1.8.1 新增，未安装时静默降级）
- **openpyxl**：Excel 报告导出（可选）
- **pyserial**：串口通信（Web 版，1.8.2 新增）

### 应用架构
- **单文件主程序**：`main_gui.py` 约 4480 行，`MainWindow` 类
- **解析器插件化**：每种协议独立 parser 文件，统一返回嵌套 dict
- **模块化 GUI 组件**：新 UI 组件拆分到独立文件，由 `main_gui.py` 导入组合
- **校验器架构**：`BaseValidator` + 各协议 validator，统一 `ValidationResult`

### 数据存储
- **主要存储**：JSON 文件（配置、档案、测试计划、预设命令）
- **无数据库**：所有数据持久化到本地 JSON 文件
- **数据文件**：`custom_di.json`、`dlt645_di.json`、`gdw_custom_afn.json` 等

## 开发环境

### 构建工具
- **PyInstaller**：打包为 Windows EXE
  - `协议解析工具.spec`：完整版（4个datas，COLLECT目录型）
  - `南网协议解析工具.spec`：精简版（5个datas，单文件EXE）
  - **两个 spec 的 datas 和 excludes 不完全相同**，新增数据文件时必须同步检查
- **Inno Setup**：安装包制作（版本号需手动同步 `APP_VERSION`）

### 代码质量
- **无正式测试框架**：无 pytest/unittest，测试为独立脚本直接运行
- **静态分析**：无 linter/formatter 配置
- **类型提示**：部分使用，非强制

### 版本控制
- **Git**：标准 Git 工作流
- **分支策略**：主分支开发，功能完成后合并

## 技术要求与约束

### 性能要求
- **单帧解析**：毫秒级响应
- **批量解析**：支持大输入量，监控器环形缓冲 `deque(maxlen=1000)`
- **实时监控**：30ms 静默间隔组帧，需保证流畅

### 兼容性要求
- **平台支持**：Windows 10/11 优先，Linux/Mac 基础支持
- **Python 版本**：3.8+
- **编码兼容**：UTF-8/GBK 双编码支持（中文路径/报文内容）

### 安全与合规
- **无网络通信**：纯本地工具，无远程数据传输
- **串口通信**：需注意串口权限与波特率配置
- **数据安全**：本地 JSON 文件存储，无加密需求

### 可靠性
- **解析准确性**：必须严格遵循协议标准文档
- **容错处理**：非法报文不崩溃，返回错误提示
- **无热重载**：代码修改后需重启 GUI 应用

## 技术决策与理由

### 决策日志
1. **单文件主程序**：`main_gui.py` 集中 GUI 逻辑，便于维护但增长迅速（4480行），新 UI 组件已拆分到独立文件
2. **嵌套 dict 返回**：所有 parser 返回嵌套 dict，禁止返回自定义类给 GUI 层，保证接口统一
3. **延迟导入**：698.45 APDU 解析器用 `@property` 延迟初始化，避免循环依赖
4. **无正式测试**：项目处于快速迭代期，测试脚本直接运行而非框架化

## 已知限制
- **main_gui.py 过大**：4480行单文件，后续可能需要进一步拆分
- **无自动化测试**：无 pytest/unittest，回归测试依赖手动验证
- **版本号同步**：Inno Setup 的 `MyAppVersion` 需手动同步 `APP_VERSION`
- **PyInstaller datas 同步**：两个 spec 文件的数据包列表需手动保持一致

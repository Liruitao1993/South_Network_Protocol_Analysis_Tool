新一代计量自动化主站通信网络管理

技术要求

**1、概述**

本技术要求规定了主站和计量自动化终端之间、计量自动化终端和远程通信模块之间、计量自动化终端和集中器本地通信模块之间、集中器本地通信模块与电表通信模块之间的通信网络管理数据交互，实现主站对业务端到端全链路通信的网络管理。

**2、新一代计量自动化主站通信网络架构**

新一代计量自动化主站通信架构由上而下包括：主站、远程通信模块（4G）、集中器终端、集中器本地载波模块（CCO）、电表通信载波模块（STA）

主站：实现通信网络管理可视化展示、远程配置等功能，需满足完成网络管理功能扩展的Q/CSG1209022-2019《中国南方电网有限责任公司计量自动化终端上行通信规约》。

远程通信模块（4G）：在原有的功能基础上，扩展支持远程通信网络管理功能，涉及接口协议规范有Q/CSG1209023-2019《计量自动化终端远程通信模块接口协议（试行）》、《南方电网无线蜂窝通信接入设备技术规范》。

集中器终端：在原有的功能基础上，扩展支持本地载波网络管理数据上报主站功能。涉及接口协议规范有：Q/CSG1209022-2019《中国南方电网有限责任公司计量自动化终端上行通信规约》、Q/CSG1209021-2019《计量自动化终端本地通信模块接口协议（试行）》、Q/CSG1209023-2019《计量自动化终端远程通信模块接口协议（试行）》

集中器本地载波模块（CCO）：在原有的功能基础上，扩展支持本地载波网络管理数据与集中器终端交互功能，涉及接口协议规范有：Q/CSG1204111.4-2022《低压电力线宽带载波通信规约 第4部分：数据链路层通信协议（试行）》、Q/CSG1204111.5-2022《低压电力线宽带载波通信规约 第5部分：应用层通信协议（试行）》、Q/CSG1209021-2019《计量自动化终端本地通信模块接口协议（试行）》。

电表通信模块（STA）：符合Q/CSG1204111.4-2022《低压电力线宽带载波通信规约 第4部分：数据链路层通信协议（试行）》、Q/CSG1204111.5-2022《低压电力线宽带载波通信规约 第5部分：应用层通信协议（试行）》，即满足本地载波网络管理功能。

3.1 主站功能要求

新一代计量自动化主站远程通信网管及本地通信网管通信网络总览统计，包括：支持远程通信网管能力台区数量统计、支持本地通信网管能力台区数量统计、远程及本地通信告警统计、远程及本地通信网络监测统计，并支持图形和列表展示。

7.4参数

|  |  |
| --- | --- |
| <type> | 协议类型。  1：南方电网5G技术应用标准 第2部分：电力通信终端技术要求(1)(3)。  2：暂未实现。  3：南方电网无线蜂窝通信接入设备测试规范(新版草稿)v1.2 |
| <hex> | 回码数据输出类型。  0：<data>格式与规约子包的格式相同。  1：<data>格式转换为HEX字符串的格式输出。 |
| <cmd> | 要查询的CMD ID字符串。  CMD ID格式是将规约中2字节的CMD字段转换为4个字节的HEX字符串格式。  4个字节为一个CMD ID，一个指令可包含多个CMD ID，最多包含100个。 |
| <length> | <data>的长度。  最长支持2048，如果查询结果超过2048，只返回前面CMD的查询结果。 |
| <data> | 查询的模块信息。  由一个或多个子包组成，也可能为空。  子包与规约中的子包格式相同，由CMD+数据长度+数据域三个字段组成一个子包。  当<hex>为1，则<data>将转换为HEX字符串的格式输出。 |
| 当<hex>为0，<data>将会包含‘\0’或其它特殊字符。 |

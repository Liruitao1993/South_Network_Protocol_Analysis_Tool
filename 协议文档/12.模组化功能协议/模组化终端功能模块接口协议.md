# 1　 范围

本标准规定了模组化终端功能模块接口的通信架构、数据链路层以及功能模块应用层数据传输协议。

本标准适用于用模组化终端（以下简称“终端”）、功能模块（以下简称“模块”）之间的通信数据交换。

# 3　 术语和定义

CDC-ECM (Ethernet Networking Control Model)

通信设备类以太网控制模型，可以用于主从设备间以太网数据的交互

CDC-ACM (Abstract Control Model)

通信设备类抽象控制模型，可以用于模拟UART

HID（Human Interface Device）

人机接口设备

USB Composite Device

USB组合设备是指具有多个接口且接口间相互独立的USB设备

# 4　 通信架构

## 4.1　 概述

本协议定义了终端与功能模块之间的接口通信协议，终端与功能模块之间的物理通信通道为USB（通用串行总线）。终端作为主设备（USB Host），功能模块作为从设备（USB Device）,功能模块设计为USB组合设备，功能模块应至少支持1个以上子设备接口, USB设备的VID与PID定义见附　录　B。设备模型如下图所示。

Embedded object: Visio.Drawing.11

- 图1　 功能模块设备模型

功能模块子设备接口类型可分为如下三种：

- 1\) 虚拟串口设备 — CDC-ACM模式；
- 2\) ECM网口设备  — CDC-ECM模式；
- 3\) 人机接口设备 — HID模式。

## 4.2　 信息交换模型

本协议信息交换模型见图2　。

Embedded object: Visio.Drawing.11

- 图2　 信息交换模型

功能模块的USB接口实现为USB Composite Device，每一个子设备接口对应一个虚拟通道，功能模块子设备接口特征及数量由功能模块定义，虚拟通道1对应子设备接口1，为管理通道，必须为“CDC-ACM串口设备”，其他虚拟通道为数据传输通道。

本协议定义了终端与功能模块之间通过虚拟通道1传输的接口控制协议。通过数据传输通道传输的数据命令协议，由各功能模块定义，具体见附录C—附录J。

## 4.3　 链路会话协商

终端检测到功能模块接入后，主动发起链路会话协商，流程如下：

Embedded object: Visio.Drawing.11

- 图3　 终端主动请求链路协商时序

终端和功能模块链路会话协商完成之后，双方可以基于协商后的通信模式进行数据传输以及控制命令传输。

## 4.4　 平衡传输过程

所有虚拟通道均为全双工接口，可采用平衡传输规则。

链路层帧的基本单元为8位字节，传输顺序为低位在前，高位在后；低字节在前，高字节在后。

传输方向位及启动标志位定义：

#### 5.2.3.3　 帧序号

帧序号从0开始，循环使用，启动站每发送1帧报文，帧序号加1，重发帧则不加1；响应报文帧序号应与请求报文帧序号一致。

/*

\* Calculate a new fcs given the current fcs and the new data.

\*/

u16 pppfcs16(fcs， cp， len)

register u16 fcs;

register unsigned char *cp;

register int len;

{

ASSERT(sizeof (u16) == 2);

ASSERT(((u16) -1) > 0);

while (len--)

fcs=(fcs >> 8) ^ fcstab\[(fcs ^ *cp++) & 0xff];

return (fcs);

}

/*

\* How to use the fcs

\*/

tryfcs16(cp， len)

register unsigned char *cp;

register int len;

{

u16 trialfcs;

/* add on output */

trialfcs=pppfcs16( PPPINITFCS16， cp， len );

trialfcs ^= 0xffff; /* complement */

cp\[len]=(trialfcs & 0x00ff); /* least significant byte first */

cp\[len+1]=((trialfcs >> 8) & 0x00ff);

/* check on input */

trialfcs=pppfcs16( PPPINITFCS16， cp， len + 2 );

if ( trialfcs == PPPGOODFCS16 )

printf("Good FCS\\n");

}

/*

\* NOTE The hex to "least significant bit" binary always causes

\* confusion， but it is used in all HDLC documents. Example： 03H

\* (0x8408) is required by the algorithm to produce the results

\* corresponding to the given generator polynomial

\*/

main()

{

register unsigned int b， v;

register int i;

printf("typedef unsigned short u16;\\n");

printf("static u16 fcstab\[256]={");

for (b=0; ; )

{

if (b % 8 == 0)

printf("\\n");

v=b;

for (i=8; i--; )

v=v & 1 ? (v >> 1) ^ P ： v >> 1;

printf("\\t0x%04x"， v & 0xFFFF);

}

}

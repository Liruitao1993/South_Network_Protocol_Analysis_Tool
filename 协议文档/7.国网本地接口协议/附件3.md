前  言

Q/GDW 376—2012《电力用户用电信息采集系统通信协议》是根据国家电网公司2012年度企业标准制修订计划任务（国家电网科[2012]66号）的安排，对Q/GDW 376—2009《电力用户用电信息采集系统通信协议》的修订。

与原标准相比，本次修订做了如下重大调整和修订：

1. 增加了磁场异常事件记录；
2. 增加了终端对时事件记录；
3. 增加了集中器与本地通信模块交互流程；
4. 增加了采集终端远程通信模块接口协议（Q/GDW 376的第3部分）。

Q/GDW 376—2012《电力用户用电信息采集系统通信协议》分为下列3个部分：

1. Q/GDW 376.1《电力用户用电信息采集系统通信协议 第1部分：主站与采集终端通信协议》；
2. Q/GDW 376.2《电力用户用电信息采集系统通信协议 第2部分：集中器本地通信模块接口协议》；
3. Q/GDW 376.3《电力用户用电信息采集系统通信协议 第3部分：采集终端远程通信模块接口协议》。

Q/GDW 376—2012实施后代替Q/GDW 376—2009。

本部分是Q/GDW 376—2012《电力用户用电信息采集系统通信协议》的第2部分。

电力用户用电信息采集系统通信协议
第2部分：集中器本地通信模块接口协议

1. 范围

本部分规定了电力用户用电信息采集系统中集中器与本地通信模块接口间进行数据传输的帧格式、数据编码及传输规则。

本部分适用于采用低压电力线载波、微功率无线通信、以太网传输通道的本地通信组网方式，适用于集中器与本地通信模块间数据交换。

术语和定义

下列术语和定义适用于本部分。

主节点 primary node

集中器所在的本地通信模块。

从节点 secondary node

采集器或计量点（电能表）所在的本地通信模块。

从节点附属节点 sub node of secondary node

指与从节点具有绑定关系的附加设备，简称附属节点。

相别 relative to other

对应于节点信道时序物理相线，取值为1，2，3。

信道标识 channel ID

载波通信报文传输相别。

信号品质 signal quality

表达节点对载波信号质量的量化值，取值范围1—15。

源地址 source address

传输数据帧的起始发送方的节点MAC地址。

中继地址 relay address

传输数据帧时进行中继传送的节点MAC地址。

目的地址 destination address

传输数据帧的最终接收方的节点MAC地址。

中继器 repeater

载波组网中提供中继的载波节点。

路由器 router

路由器负责启动中继数据包来实现电力线网络互连。

1. 传输帧格式
   * 1. 传输规则

线路空闲状态为二进制1。

帧的字符之间无线路空闲间隔。

如按d）检出了差错，两帧之间的线路空闲间隔最少需33位。

接收方校验：

* 1. 对于每个字符：校验起动位、停止位、偶校验位。
  2. 对于每帧：
     1. 检验帧的固定报文头中的起始字符；
     2. 识别1个长度L；
     3. 每帧接收的字符数为用户数据长度L1+6；
     4. 帧校验和；
     5. 结束字符；
     6. 校验出一个差错时，校验按c）的线路空闲间隔。

若这些校验有一个失败，舍弃此帧；若无差错，则此帧数据有效。

长度L是指帧数据的总长度，由2字节组成，BIN格式，包括用户数据长度L1和6个字节的固定长度（起始字符、长度、控制域、校验和、结束字符），长度L不大于65535。模块和终端支持的长度不少于2048字节。

1. 控制域定义
   * + 1. 传输方向位DIR

DIR=0：表示此帧报文是由集中器发出的下行报文；DIR=1：表示此帧报文是由通信模块发出的上行报文。

* + - 1. 启动标志位PRM

PRM =1：表示此帧报文来自启动站；PRM =0：表示此帧报文来自从动站。

集中器与本地通信模块交互流程

**(见附件)**

* 1. 一般要求

定义集中器本地通信单元空闲管脚，用以识别集中器是否接入本地通信单元；使用管脚为18脚，低电平为本地通信单元接入，高电平为本地通信单元未接入。

集中器复位模块电平持续时间不小于200ms（取消，模块自身应有可靠的硬件看门狗）；集中器与通信单元直接交互命令响应时间小于6s（不含本地通信环节）。

外置通信模块结构与安装在集中器本体的通信模块一样，模块通过串口转接线连接到集中器的调试串口。

集中器对各类任务处理优先级：

广播命令=主动注册>非广播计划任务（穿透抄表、读取通信模块版本信息）（非广播计划任务中按任务优先级决定）。

**为防止由于集中器与模块信息交互异常或模块异常问题，集中器在下发“启动预告任务执行”后，**若本地通信模块“**超过AFn=54H：F2本地通信模块应用响应超时时间（默认10分钟）”没有申请具体抄读对象”或“已经申请了具体抄读内容但**“**超过AFn=54H：F2本地通信模块应用响应超时时间（默认10分钟）”内没有回应响应报文”时，集中器应认为该任务为超时失败，生成该具体任务执行结果（该具体任务执行结果为超时失败），并下发结束当前任务命令，重新预告未完成的任务。**

当有主动上报报文时，集中器应能存储主动上报报文（存储不超过255个），是否进一步处理待今后扩充。

本地通信模块主动上报重试次数不超过2次，上报失败后不再上报。

1. 本地通信模块应在终端有下发抄表任务时才能开始抄表，当无抄表任务时，不得抄表。
2. 本地通信模块在收到抄表任务后根据需要抄读的对象，首次申请必须在30秒内选择通信模块自身认为最佳的抄读对象进行具体的抄读内容请求，一般选择有利于提高整体通信成功率的对象先抄读；**当还有已经预告的任务未完成时，后续申请时间不超过**“**AFn=54H：F2本地通信模块应用响应超时时间（默认10分钟）”（从上一次主动上报完“预告的通信对象响应报文”后开始计算）。**
3. 进行具体的抄读内容请求后，无论最终是否通信成功，本地通信模块最长不超过10分钟应回复抄读结果（回复报文或错误类型码）。
4. 本地通信模块要实现的特殊的参数、数据功能（例如发射功率、噪声情况、路由信息等）、软件升级等，采用报文透明转发模式实现（具体报文由各厂家提供后，由主站封包实现）。
   1. 识别流程

当通信信道配置有配置本地通信模块时，集中器应在终端上电时、每15分钟检测模块是否接入。检测方法为读取本地通信模块的版本信息，配置参数信息。每次检测的次数不少于2次，两次获得的信息有效且一致时，则开始按该参数设置。

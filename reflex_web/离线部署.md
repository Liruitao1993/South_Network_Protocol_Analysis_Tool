# Reflex Web 离线部署（UV）

## 用途

局域网目标服务器没有外网时，可以在一台有网机器上用 UV 生成一个“可迁移部署目录”，
把该目录整体拷到目标服务器后直接启动 Web 服务。

部署目录包含：

- `requirements.in`：直接依赖清单
- `requirements.lock`：UV 解析出的完整锁定依赖
- `.venv`：基于 `uv venv --relocatable` 构建的虚拟环境
- `reflex_web/.web/build/client`：预编译前端
- 协议解析器、校验器、JSON 数据和启动脚本

## 构建（有网机器）

```powershell
python reflex_web\build_offline_deploy.py --python-version 3.12
```

默认输出到 `dist\reflex_web_offline`。

如果前端尚未编译，脚本会尝试执行：

```powershell
cd reflex_web
reflex export --frontend-only --env prod --no-zip
```

## 部署（无网目标服务器）

把 `dist\reflex_web_offline` 整个目录复制到目标服务器，然后运行：

Windows：

```powershell
cd C:\path\to\reflex_web_offline
start_web.cmd
```

Linux：

```bash
cd /opt/reflex_web_offline
chmod +x start_web.sh
./start_web.sh
```

访问地址：

```text
http://服务器IP:8080
```

如需修改端口：

```powershell
start_web.cmd --port 9000
```

## 注意事项

- `.venv` 只能在相同操作系统、相同 CPU 架构、相同 Python 大版本之间复制。
- 目标服务器仍需要存在同版本 Python 解释器；`.venv` 不包含 Python 运行时本体。
- `reflex_web/.web` 是前端构建产物，必须包含在部署目录中，目标服务器不需要 Node.js。

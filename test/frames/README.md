# 真实帧语料库（golden corpus）

用途：给「解析准确性」加一道与实现无关的护栏。每个 `.hex` 文件放**一帧**报文，
测试会逐帧解析并断言「不抛异常 + 解析结果非空」。

约定：

- 目录名 = `parser_registry` 的 key（如 `south`、`dl_t698_45`、`dlt645`）；
- 文件内容：十六进制，可带空格/换行；`#` 开头的行是注释；
- 新增协议时建同名目录，至少放 3 条**现场脱敏实帧**（去掉真实表号/用户数据后仍能过校验）；
- 修改解析器后跑 `python test/test_frame_corpus.py`，这里的帧必须一条都不回归。

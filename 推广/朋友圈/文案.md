## 发布小技巧

1. **首图用竖版海报**，第二张放解析截图——信息流里先看到"这是什么"，再看到"长什么样"。
2. 朋友圈正文里的链接不可点，**统一写"GitHub 搜 xxx"**；如果要发链接，放在**第一条评论**里。
3. 发完自己先评论一条补充：
   > 补充：支持串口 / 蓝牙 / TCP 监控；698.45 升级会前后各读一次版本自动比对；产线测试架那页是这次新加的，参数表可以自己配。
4. 发布时间：工作日 **20:00–22:00** 或午休 12:00–13:00，同行在线率高。
5. 同一张海报**不要一天发多次**；隔 3~5 天换一张截图 + 换一段文案再发，效果更好。
6. 有人问"怎么下载"时，直接回 GitHub 链接，并顺手问一句"你主要用哪个协议？"——这是最好的需求调研。

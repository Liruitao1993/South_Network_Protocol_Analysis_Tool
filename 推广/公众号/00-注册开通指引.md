# 个人公众号：注册与开号指引（给瑞涛）

> 公众号的注册与发布**必须你本人操作**：需要身份证、实名微信扫码、人脸核验和手机验证码，
> 我不能代替你注册或登录。下面把要准备的东西、每一步点什么、开号后的设置全部列好，
> 你照着做大约 15 分钟能提交，审核通常 1~3 个工作日。

## 一、先准备（5 分钟）

| 材料 | 说明 |
|------|------|
| 邮箱 | **从未注册过公众号**的邮箱（QQ 邮箱即可），用来做登录账号并接收激活信 |
| 微信 | 你本人**已实名 + 已绑银行卡**的微信（管理员扫码 / 人脸核验用） |
| 身份证 | 信息与微信实名一致；按页面提示拍摄/核验 |
| 手机号 | 接收短信验证码 |
| 名称 / 简介 / 头像 | 见第三节，**名称一年只能改 2 次**，先想好 |

个人主体只能注册**订阅号**（每天可群发 1 次）；服务号仅企业/个体户可申请。
注册本身免费，个人号不涉及企业认证年费。

## 二、注册步骤（电脑端，推荐）

1. 打开 **https://mp.weixin.qq.com/** → 右上角「立即注册」→ 选「公众号」。
2. 填邮箱 → 点「激活邮箱」→ 去邮箱点激活链接 → 回填验证码 → 设置密码。
3. 账号类型选 **订阅号**（选定后不可更改）。
4. 主体类型选 **个人** → 填姓名、身份证号 → 用管理员的微信扫码，按提示完成人脸核验。
5. 填手机号 → 收短信验证码。
6. 设置 **名称、头像、功能介绍（简介）** → 提交，等待审核（一般 1~3 个工作日）。

> 若页面要求"手持身份证照片"，保证四角完整、信息清晰、无反光。
> 个人号数量以平台提示为准（通常一张身份证 1 个个人号），别用已注册过的邮箱。

## 三、名称 / 简介 / 头像（建议直接采用或微调）

**名称候选（按推荐顺序）**
1. **电力协议工具箱** —— 一眼看懂、便于搜索，和产品定位一致
2. **瑞涛的协议笔记** —— 个人 IP 路线，适合长期写技术拆解
3. **载波与协议解析** —— 更垂直，同行一看就知道对口

> 名称里不要出现「官方」「第一」「最」等词，也不要蹭政务/金融类敏感词。

**简介（30 字内备选）**
- 电力通信协议解析与测试工具，15 种规约的报文拆解、组帧与现场排障笔记。
- 一个电力测试工程师的工具箱：南网 / 国网 / 698.45 / 645 / 载波双模。

**头像**
- 直接用程序图标：`app_icon.ico`（导出 300×300 PNG），或海报左上角的「南解」logo 方块。
- 头像每月可改 5 次，先用图标，等有真人形象照再换。

## 四、开号后的基础设置（10 分钟）

1. **自动回复 → 关键词回复**：关键词 `工具` / `下载` / `软件`，回复：
   > 「南网协议解析工具」Windows 单文件版：
   > https://github.com/Liruitao1993/South_Network_Protocol_Analysis_Tool/releases/latest
   > 解压后双击即用，无需安装 Python；有问题直接在这里留言。
2. **被关注回复**：一句话介绍 + 引导回复「工具」获取下载 + 说明主要写什么。
3. **自定义菜单**（3 个）：
   - `下载工具` → 跳转 GitHub Releases
   - `使用说明` → 图文《3 分钟上手》
   - `联系我` → 留你的邮箱/微信（不建议直接放手机号）
4. **页面模板**：把「工具介绍 / 更新记录 / 使用教程」做成一个列表页，方便新读者翻。

## 五、发第一篇文章

1. 后台「内容与互动 → 图文消息 → 新建」。
2. 标题 + 作者 + 正文：可以直接用 `01-首篇推文.md` 的内容，按段落粘进去。
3. 图片按文中标记上传（`docs/images/` 里的截图 + `推广/朋友圈/` 的海报）。
4. 勾选「原创」（自己的文字和截图，可以声明）。
5. 先「预览」发给自己微信看一遍排版，再「群发」。
6. 群发后把文章转发到朋友圈，配 `推广/朋友圈/文案.md` 里的一段话。

## 六、合规与体验提醒

- 不写「最好用」「第一」「保证解决」这类绝对化/承诺性表述；写清「支持哪些协议、验证到什么程度」。
- 截图里的**表号、地址、公司名**打码或改成示例值。
- 软件是 MIT 开源，文章里可以提「开源免费」，但不要说「永久免费」。
- 读者提问尽量当天回；早期 20 个真实用户比 2000 个阅读更有价值。
